A

Abstract Class

Object-Oriented Paradigm

A class that cannot be instantiated directly and exists purely to be subclassed. Abstract classes often define method signatures that subclasses must implement, enforcing a consistent interface across a family of types.

Example: A Shape class declares area() but only Circle and Square subclasses can be created.

See also: Class, Inheritance

Abstraction

Programming Fundamentals Object-Oriented Paradigm

The concept of hiding complex internal implementation details while exposing only the necessary interface to the user or calling code. Reduces cognitive complexity and increases maintainability.

Example: Calling send_email(to, body) without knowing how the mail server connection works.

See also: Encapsulation

Acceptance Criteria

SDLC Software Engineering Project

Specific, measurable conditions that must be met to confirm a user story has been implemented correctly. They provide a clear definition of "done" for each requirement.

Example: "Given a wrong password three times, the account locks for 15 minutes."

See also: User Stories, UAT

Access Modifier

Object-Oriented Paradigm

Keywords (such as public, private, and protected) that control the visibility and accessibility of class members. They enforce encapsulation by restricting which parts of a program can access specific attributes or methods.

Example: Marking balance as private so only deposit() and withdraw() can change it.

See also: Encapsulation

Accountability

Secure Software Architecture

The principle of tracing every action back to a specific authenticated user through immutable audit logs. Ensures that no action can be performed anonymously within a secure system.

Example: An audit log records that user jchen deleted invoice #204 at 10:14 am.

See also: Authentication, Authorisation

Actuator

Programming Mechatronics

An output component that converts electrical energy into physical motion, such as a motor, solenoid, or pneumatic piston. Actuators enable a mechatronic system to interact with the physical world.

Example: A servo motor that opens a greenhouse vent when the temperature rises.

See also: Sensor, Servo Motor

ADC (Analog-to-Digital Converter)

Programming Mechatronics

A component that samples continuous analog voltages and converts them into discrete digital numbers for processing by a microcontroller. Resolution is measured in bits (e.g., a 10-bit ADC yields 1024 distinct values).

Example: An Arduino reading a light sensor as a number from 0 to 1023.

Address Register

Programming Mechatronics

A small, fast storage location inside a processor that holds the memory address of data or of the next instruction to fetch.

Example: While running a loop, the program counter (an address register) points to the next instruction in flash memory.

Agile Methodology

SDLC Software Engineering Project

An iterative and incremental approach to software development focusing on flexibility, responsiveness to change, and frequent client feedback. Agile prioritises working software and customer collaboration over rigid upfront specification.

Example: A team releases a school canteen app in two-week sprints, changing features after student feedback.

See also: Scrum, WAGILE, Sprint

Artificial Intelligence (AI)

Software Automation

The broad field of building machines that can simulate human cognitive functions such as learning, reasoning, and problem-solving. AI encompasses many sub-fields including machine learning, natural language processing, and computer vision.

Example: A chatbot that answers enrolment questions on a school website.

See also: Machine Learning, Neural Network

Algorithm

Programming Fundamentals SDLC

A step-by-step procedure required to solve a problem or accomplish a task, defined by its efficiency, clarity, and finiteness. Every algorithm must eventually terminate with a definite result.

Example: The steps to find the largest mark in a class list.

See also: Pseudocode, Flowchart

API (Application Programming Interface)

Programming for the Web Software Automation

A contract defining how different software components communicate, specifying request formats and expected responses — without exposing implementation details.

Example: A weather app requests GET /forecast?city=Sydney from the Bureau of Meteorology's servers.

See also: REST

Array

Programming Fundamentals

A data structure consisting of a collection of elements identified by at least one index or key, stored in contiguous memory locations. Arrays provide O(1) access by index.

Example: marks = [72, 85, 64], where marks[1] is 85.

See also: Variable

Asymmetric Encryption

Secure Software Architecture

An encryption method using a mathematically linked public and private key pair. The public key encrypts data (or verifies signatures), while only the corresponding private key can decrypt (or sign). Used for secure key exchange and digital signatures.

Example: A browser encrypts a session key with a bank's public key; only the bank's private key can read it.

See also: Symmetric Encryption, Digital Signature

Attack Surface

Secure Software Architecture

The total number of possible ways an attacker can interact with or compromise a software system. Minimising the attack surface — by reducing exposed endpoints, disabling unused features, and enforcing least privilege — is a core security principle.

Example: Closing an unused admin login page removes one way in for attackers.

Attribute

Object-Oriented Paradigm

A data element or property defined within a class that stores the state of an object. For example, a Car class might have attributes like colour, speed, and fuel_level.

See also: Method, Class

Authentication

Secure Software Architecture

The process of verifying the identity of a user or system, often using passwords, biometrics, or multi-factor authentication (MFA). Answers the question: "Who are you?"

Example: Logging in with a password plus a code from an authenticator app.

See also: Authorisation, JWT

Authorisation

Secure Software Architecture

The process of determining what an authenticated user is permitted to do, based on the principle of least privilege. Answers the question: "What are you allowed to do?"

Example: A student can view their own results but only a teacher can edit them.

See also: Authentication, Accountability

Availability

Secure Software Architecture

Ensuring that systems and data remain operational and accessible to authorised users when needed. One of the three pillars of the CIA triad alongside Confidentiality and Integrity.

Example: A school portal stays online during exam results release despite heavy traffic.

See also: Confidentiality, Integrity

B

Backlog (Product Backlog)

SDLC Software Engineering Project

A prioritised list of all features, user stories, and bug fixes yet to be completed for a product. In Scrum, the Product Backlog is the single source of work for the development team.

Example: "Add dark mode" sits in the backlog below the higher-priority "Fix login bug".

See also: Scrum, Sprint

Backpropagation

Software Automation

The training process where prediction error is propagated backwards through a neural network to adjust connection weights using gradient descent. This iterative process minimises the loss function over many epochs.

Example: After predicting "cat" for a dog photo, the network nudges its weights to reduce that error.

See also: Neural Network, Overfitting

Back-end

Programming for the Web

The server-side portion of a web application responsible for business logic, database queries, authentication, and security enforcement. Users never interact with back-end code directly.

Example: The Flask server code that checks a login and queries the database.

See also: Front-end Framework, REST

Backtracking

Programming Fundamentals

An algorithm design strategy that builds a solution step by step and, when a step leads to a dead end, undoes it and tries a different choice.

Example: Solving a maze by following a path until it is blocked, then stepping back to the last junction and trying another way.

Big Data

Programming for the Web Software Automation

Data sets so large, fast-changing or varied that ordinary tools cannot store or process them, so distributed systems are needed.

Example: Every song played by every Spotify user each day.

Binary Search

Programming Fundamentals

An efficient algorithm that finds an item in a sorted list by repeatedly dividing the search interval in half. It has a time complexity of O(log n), making it far faster than linear search for large datasets.

Example: Finding 21 in [3, 5, 8, 12, 17, 21, 26, 30] in two comparisons by halving the list.

See also: Linear Search

Black-Box Testing

SDLC Object-Oriented Paradigm

Testing software by checking outputs against expected results for given inputs, without looking at the code inside.

Example: Entering valid, boundary and invalid marks into a grading program and checking the grades it returns.

Boolean

Programming Fundamentals

A logical data type that represents one of two values: True or False. Booleans are fundamental to control flow, conditions, and logical expressions in every programming language.

Example: is_logged_in = True

See also: Selection

Bottom-Up Design

Programming Fundamentals Object-Oriented Paradigm

Designing a system by first building and testing small, reusable components, then combining them into larger parts.

Example: Writing and testing validate_email() and hash_password() before building the registration page that uses them.

Boundary Value

Programming Fundamentals Software Engineering Project

Test data at, just inside and just outside the limits of a valid range, where off-by-one errors are most likely.

Example: For marks from 0 to 100: −1, 0, 1, 99, 100 and 101.

Breakpoint

Programming Fundamentals

A marker set in an IDE that pauses a program at a chosen line so the programmer can inspect variables.

Example: Pausing at the line total += price to check the value of price on each loop.

Business Process Automation (BPA)

Software Automation

Using software to automate a complete business workflow across people and systems, not just single tasks.

Example: A leave request that is submitted online, approved by a manager and updated in payroll without any paperwork.

C

CDN (Content Delivery Network)

Programming for the Web

A geographically distributed network of servers that caches and serves static assets (images, CSS, JS) from locations close to the user, reducing latency and improving load times.

Example: A video site serves Sydney users from a Sydney server instead of one in the USA.

CI/CD (Continuous Integration / Continuous Deployment)

Software Automation

A DevOps practice where code changes are automatically built, tested (CI) and deployed to staging or production environments (CD). Enables rapid, reliable delivery cycles with minimal manual intervention.

Example: Every push to GitHub runs the tests automatically and deploys if they pass.

See also: DevOps

Cipher Text

Programming for the Web Secure Software Architecture

Data after encryption, which is unreadable without the correct key.

Example: "Hello" encrypted with AES might become 9f2c4e….

Class

Object-Oriented Paradigm

A blueprint or template defining the structure (attributes) and behaviour (methods) for a family of objects. Instantiation creates an individual Object from the class definition in memory.

Example: A Student class defines a name, ID and enrol() method.

See also: Object, Inheritance, Class Diagram

Class Diagram

Object-Oriented Paradigm SDLC

A UML diagram that represents classes, their attributes, methods, and the relationships (inheritance, composition, association) between them. A key deliverable in the Design phase of OOP projects.

Example: A box for Book listing title, isbn and borrow(), linked to Library.

See also: UML, Class

Closed Loop System

Programming Mechatronics

A control system that uses sensor feedback to continuously adjust its output in real-time. The feedback loop allows the system to self-correct and maintain a desired state despite disturbances.

Example: A robot vacuum uses a bump sensor to change direction when it hits a wall.

See also: Open Loop System, PID Control

Code Review

SDLC Software Engineering Project

A systematic peer examination of source code to find defects, ensure adherence to coding standards, and share knowledge before merging changes into the main codebase.

Example: A teammate spots a missing input check before a pull request is merged.

See also: Version Control

Cohesion

Programming Fundamentals Object-Oriented Paradigm

A measure of how closely related the responsibilities of a single module or class are. High cohesion (single-responsibility) is a hallmark of good design — each unit does one thing well.

Example: A ReportPrinter class that only formats and prints reports (high cohesion).

See also: Coupling

Composition

Object-Oriented Paradigm

A strong "has-a" relationship where parts cannot exist independently of the whole. For example, a Room cannot exist without a Building. Contrasts with aggregation, where parts can exist independently.

See also: Inheritance, Class Diagram

Computational Thinking

Programming Fundamentals

A way of solving problems using decomposition, pattern recognition, abstraction and algorithm design.

Example: Breaking "run the school canteen online" into ordering, paying and preparing, each solved separately.

Confidentiality

Secure Software Architecture

Ensuring that sensitive data is accessible only to authorised entities through encryption and access controls. One of the three pillars of the CIA triad.

Example: Encrypting medical records so only the patient's doctor can read them.

See also: Integrity, Availability

Confusion Matrix

Software Automation

A table summarising prediction results for a classification model, showing counts of True Positives, True Negatives, False Positives, and False Negatives. Used to calculate metrics like accuracy, precision, and recall.

Example: A spam filter with 90 true positives, 5 false positives, 8 false negatives and 97 true negatives.

Constructor

Object-Oriented Paradigm

A special method (such as __init__ in Python or the class-named method in Java) that initialises an object's state when it is first created. Constructors set default attribute values and perform setup logic.

Example: def __init__(self, name): self.name = name

See also: Class, Object

Content Management System (CMS)

Programming for the Web

Software that lets people create, edit and publish web content through an interface rather than by writing code.

Example: Teachers posting school news in WordPress.

Copyright

Secure Software Architecture

The legal right of creators to control how their original work, including source code, is copied and used.

Example: Reusing code from a tutorial only as its licence allows, and crediting the author.

CORS (Cross-Origin Resource Sharing)

Programming for the Web Secure Software Architecture

A browser security mechanism that uses HTTP headers to permit or restrict resource requests from different origins. Prevents malicious websites from making unauthorised API calls on behalf of users.

Example: A server allows requests from myschool.edu.au but blocks scripts from other sites.

See also: CSRF, HTTPS

Coupling

Object-Oriented Paradigm Secure Software Architecture

The degree of interdependence between software modules. Loose coupling — minimising direct knowledge between modules — improves maintainability, testability, and security isolation.

Example: A login module that calls a shared UserService rather than reading the database directly (loose coupling).

See also: Cohesion

Cryptography

Secure Software Architecture Programming for the Web

The use of mathematical techniques such as encryption, hashing and digital signatures to protect data and verify identity.

Example: Encrypting stored credit card numbers and hashing passwords.

CSRF (Cross-Site Request Forgery)

Secure Software Architecture

An attack that tricks an authenticated user's browser into submitting unwanted requests to another website. Mitigated by anti-CSRF tokens, SameSite cookies, and validating the request origin.

Example: A hidden form on a malicious page makes a logged-in user's browser transfer money.

See also: XSS, CORS

CSS (Cascading Style Sheets)

Programming for the Web

A stylesheet language used to describe the visual presentation and layout of HTML documents. CSS controls colours, fonts, spacing, responsive breakpoints, and animations.

Example: h1 { color: navy; } makes every main heading navy.

See also: HTML, JavaScript

D

DAST (Dynamic Application Security Testing)

Secure Software Architecture Software Automation

Security testing performed against a running application from the outside — simulating the perspective of an attacker. Identifies vulnerabilities such as SQL injection and XSS at runtime.

Example: Running an automated scanner against a live test site to find XSS vulnerabilities.

See also: SAST, Penetration Testing

Data Dictionary

Programming Fundamentals Software Engineering Project

A metadata tool that documents every variable's name, data type, size, description, and validation rules. Essential for the Design and Implementation phases of the SDLC.

Example: student_id | integer | 8 digits | unique ID for each student.

Data Flow Diagram (DFD)

Object-Oriented Paradigm Software Engineering Project

A diagram showing how data moves between external entities, processes and data stores in a system.

Example: A student enters login details → "Verify login" process → reads the Users data store.

Data Mining

Programming for the Web Software Automation

Searching large data sets for patterns and relationships that can be used to make predictions or decisions.

Example: A supermarket finding that customers who buy nappies often buy coffee.

Data Packet

Programming for the Web

A small unit of data sent across a network, containing a header (addresses and order) and a payload (part of the message).

Example: A web page split into many packets that travel separately and are reassembled by the browser.

Data Register

Programming Mechatronics

A register inside a processor that holds a value currently being worked on.

Example: Holding a sensor reading while the processor compares it with a threshold.

Debugging

Programming Fundamentals SDLC

Finding, understanding and fixing errors in a program.

Example: Using breakpoints and a watch to discover a loop runs one time too many.

Debugging Output Statement

Programming Fundamentals

A temporary print or log statement added to code to show the value of variables while it runs.

Example: print(f"i={i}, total={total}") inside a loop.

Decimal

Programming Fundamentals

The base-10 number system, using the digits 0 to 9, that people use every day.

Example: 254 in decimal is 11111110 in binary.

Decision Tree

Software Automation

A visual machine learning model representing a series of binary questions (decisions) that branch toward a final prediction or classification. Easy to interpret but prone to overfitting on complex data.

Example: "Is it raining?" → yes: take the bus; no: "Is it far?" → …

See also: Overfitting, Supervised Learning

Degrees of Freedom (DOF)

Programming Mechatronics

The number of independent directions in which a robotic or mechanical system can move. A typical industrial robot arm has 6 DOF — three for position and three for orientation.

Example: A robot arm with a rotating base, shoulder and elbow has 3 DOF.

See also: Manipulator

Design Pattern

Object-Oriented Paradigm

A proven, reusable way to structure code that solves a common design problem.

Example: The facade pattern gives a complex payment system one simple pay() method.

Desk Checking

Programming Fundamentals

The process of manually tracing through an algorithm step-by-step with sample data using a trace table to verify correctness before coding. A key NESA examination skill.

Example: Using a trace table to follow i and total through a loop by hand.

See also: Algorithm, Debugging

DevOps

Software Automation

A software development practice that unifies development and operations teams for continuous, reliable delivery. DevOps emphasises automation, monitoring, and collaboration to shorten the development lifecycle.

Example: Developers and operations staff share one pipeline that builds, tests and monitors an app.

See also: CI/CD, MLOps

Digital Disruption

Secure Software Architecture

The change that happens when new digital technologies transform how an industry works.

Example: Streaming services replacing video rental shops.

Digital Signature

Secure Software Architecture

A cryptographic mechanism that proves the authenticity and integrity of a message using a sender's private key. Recipients verify the signature using the sender's public key.

Example: A software update is signed so users can confirm it came from the real developer.

See also: Asymmetric Encryption, Hashing

Divide and Conquer

Programming Fundamentals

An algorithm design strategy that splits a problem into smaller sub-problems of the same kind, solves them, and combines the results.

Example: Binary search repeatedly halves the list it is searching.

DNS (Domain Name System)

Programming for the Web

The system that translates human-readable domain names (e.g., example.com) into machine-readable IP addresses. Often called the "phone book of the internet."

See also: IP Address, HTTP

DOM (Document Object Model)

Programming for the Web

A tree-structured programming interface representing an HTML document. JavaScript can traverse and manipulate the DOM to dynamically update page content, structure, and style without a full page reload.

Example: document.getElementById("score").textContent = 10;

See also: JavaScript, HTML

E

E-Commerce

Programming for the Web

Buying and selling goods or services online.

Example: An online store with a shopping cart and card payments.

Encapsulation

Object-Oriented Paradigm

The bundling of data (attributes) and the methods operating on that data within a single unit (class). Access modifiers (public, private, protected) control visibility, preventing unintended external interference.

Example: A BankAccount hides balance and exposes deposit().

See also: Abstraction, Access Modifier

End Effector

Programming Mechatronics

The device at the end of a robotic arm that interacts with the environment.

Example: A gripper, suction cup or welding torch.

Exception Management

Secure Software Architecture

Handling runtime errors so a program responds safely instead of crashing or revealing sensitive details.

Example: Catching a database error and showing "Something went wrong" while logging the details privately.

F

Facade Pattern

Object-Oriented Paradigm

A design pattern providing a simplified interface to a complex set of classes, hiding underlying complexity. Example: a payment gateway's facade hides the details of multiple payment processors.

See also: Design Pattern, Abstraction

Faulty and Abnormal Data

Programming Fundamentals Software Engineering Project

Test data that is invalid or unexpected, used to check that a program rejects it safely.

Example: Entering "abc", −5 or an empty field into an age box.

Feasibility Analysis

SDLC Software Engineering Project

An assessment of whether a project is viable across scheduling, financial, technical, and operational dimensions. Conducted during the Planning phase to determine project go/no-go decisions.

Example: Checking whether a booking app can be built in 10 weeks with the school's budget.

Flowchart

Programming Fundamentals SDLC

A visual diagram using the NESA symbols (terminator for BEGIN and END, rectangle for a process, diamond for a decision, parallelogram for input or output, and a double-sided rectangle for a subprogram) connected by arrows to represent the flow of logic through an algorithm.

Example: A diamond asks "age ≥ 18?" with yes and no arrows to different processes.

See also: Algorithm, Pseudocode

Front-end Framework

Programming for the Web

Pre-built software environments (like React, Vue, or Angular) providing a structured approach to building browser user interfaces with reusable components, state management, and routing.

Example: Building a quiz interface with React components.

See also: JavaScript, Back-end

Finite State Machine (FSM)

Programming Fundamentals Programming Mechatronics

A computational model with a finite set of states, defined transitions triggered by inputs or events, and associated actions. FSMs are fundamental to modelling embedded systems, protocols, and UI logic.

Example: A traffic light cycling red → green → amber → red.

Functional Requirements

SDLC Software Engineering Project

Descriptions of the specific behaviors, features, and functions that a software system must provide. They define *what* the system should do.

Example: "The system must let students book a library room."

See also: Non-Functional Requirements

G

Gantt Chart

SDLC Software Engineering Project

A horizontal bar chart used to visualise project schedules, task durations, and dependencies over time. A key tool during the Planning phase of the SDLC.

Example: A bar for "Design" in weeks 1–2 and "Development" in weeks 3–6.

Generalisation

Object-Oriented Paradigm

The engineering process of identifying common traits among multiple classes and moving them into a shared parent class. Improves code reuse and design clarity.

Example: Moving name and email from Student and Teacher into a Person class.

See also: Inheritance, Class Diagram

Grey-Box Testing

Object-Oriented Paradigm

Testing with partial knowledge of the internal code, combining black-box and white-box approaches.

Example: Knowing a login uses a database, then testing inputs designed to probe for SQL injection.

GUI (Graphical User Interface)

Programming for the Web SDLC

An interface allowing users to interact with software through visual elements (buttons, menus, icons) rather than text commands. GUI design is evaluated against usability heuristics.

Example: A form with text boxes and a "Submit" button.

H

Hash Table

Programming Fundamentals

A data structure that stores key–value pairs and uses a hash function to find a value very quickly from its key.

Example: A Python dictionary: phone["Ava"].

Hashing

Secure Software Architecture

A one-way mathematical function that produces a fixed-length fingerprint of data. Used for secure password storage, data integrity verification, and digital signatures. Cryptographic hash functions (SHA-256, bcrypt) ensure that even identical inputs produce consistent outputs, but the original data cannot be recovered.

Example: Storing a password as its SHA-256 hash rather than as plain text.

See also: Digital Signature

Headless CMS

Programming for the Web

A back-end-only content management system that stores and delivers content via API, decoupled from any front-end presentation layer. Allows content to be rendered on any platform or framework.

Example: A school news site pulls articles from Strapi through an API.

H-Bridge

Programming Mechatronics

A circuit (such as the L298N) that allows a microcontroller to control the speed and direction of a DC motor by switching transistors to forward or reverse current flow.

Example: Reversing a robot's wheel motor by switching an L298N's inputs.

See also: PWM, Servo Motor

Hexadecimal

Programming Fundamentals

The base-16 number system, using digits 0–9 and A–F; each hex digit stands for four bits.

Example: The colour #FF0000 is pure red.

HTML (HyperText Markup Language)

Programming for the Web

The standard markup language used to define the structure and content of web pages using semantic elements like headings, paragraphs, lists, and links.

Example: <h1>Welcome</h1>

See also: CSS, JavaScript, DOM

HTTP (HyperText Transfer Protocol)

Programming for the Web

The application-layer protocol used for transferring plain-text content between clients and servers. HTTP is stateless — each request is independent.

Example: A browser sends GET /index.html and the server replies 200 OK.

See also: HTTPS, REST

HTTPS (HTTP Secure)

Programming for the Web Secure Software Architecture

A secure version of HTTP encrypted with TLS/SSL to provide confidentiality and integrity of data in transit. Required for any website handling sensitive user data.

Example: The padlock icon when logging in to online banking.

See also: TLS, HTTP
↑ Back to Top
I

I2C (Inter-Integrated Circuit)

Programming Mechatronics

A two-wire communication protocol (SDA and SCL) used to connect multiple sensors and displays to a master microcontroller. Supports multiple slave devices on the same bus.

Example: An OLED display and a temperature sensor sharing the same two wires to an Arduino.

See also: SPI, UART

IDE (Integrated Development Environment)

Programming Fundamentals Software Automation

A software application providing comprehensive facilities for development, typically including a code editor, build tools, debugger, and integrated version control.

Example: VS Code with its debugger and Git integration.

Image Recognition

Software Automation

Using ML, usually neural networks, to identify objects, people or features in images.

Example: A phone app identifying a plant from a photo.

Implementation Methods (Direct, Phased, Parallel, Pilot)

Software Engineering Project

Ways to change over from an old system to a new one: all at once (direct), in stages (phased), both running together (parallel), or at one site first (pilot).

Example: A school trials new attendance software in Year 7 only (pilot) before every year group uses it.

Inheritance

Object-Oriented Paradigm

A mechanism where a subclass (child) automatically acquires the attributes and methods of a superclass (parent), establishing an "is-a" relationship. Enables code reuse and polymorphism.

Example: class Dog(Animal): gives Dog everything Animal has.

See also: Polymorphism, Class

Instruction Set

Programming Mechatronics

The complete set of basic commands (opcodes) that a particular processor can execute.

Example: Arduino Uno code is compiled for the AVR instruction set; a Raspberry Pi uses ARM.

Integer

Programming Fundamentals

A data type for whole numbers, positive or negative, with no decimal part.

Example: students = 28

Integrity

Secure Software Architecture

Guaranteeing that data has not been maliciously or accidentally altered without detection. One of the three pillars of the CIA triad, ensured through hashing and digital signatures.

Example: A checksum shows a downloaded installer has not been altered.

See also: Confidentiality, Availability

Intellectual Property (IP)

Secure Software Architecture

Creations of the mind, such as software, designs and brand names, that the law protects.

Example: A company's source code and logo.

Internationalisation (i18n)

Programming for the Web

Designing software so it can easily be adapted to different languages, regions and writing systems.

Example: Storing all interface text in translation files and using UTF-8 so Arabic and Chinese display correctly.

Interrupt

Programming Mechatronics

A signal that causes the CPU to pause its current task and execute a special handler routine (the ISR). Interrupts enable real-time responsiveness to external events without polling.

Example: Pressing an emergency-stop button immediately halts a motor, whatever the program was doing.

See also: ISR, Polling

IP Address

Programming for the Web

A number that identifies a device on a network so data can be delivered to it. IPv4 addresses have four parts from 0 to 255.

Example: 192.168.1.20

ISR (Interrupt Service Routine)

Programming Mechatronics

A specialised function executed immediately in response to an interrupt signal. Should be short and fast to avoid missing subsequent interrupts.

Example: A short function that sets stop = True when a button pin changes.

See also: Interrupt

Iteration

Programming Fundamentals SDLC

The repetition of a process or set of instructions. In programming, refers to loops (FOR, WHILE, REPEAT/UNTIL); in management, refers to repeated development cycles in Agile.

Example: for mark in marks: total += mark

See also: Recursion, Agile
↑ Back to Top
J

JavaScript

Programming for the Web

A client-side scripting language used to create interactivity and dynamic behaviour on web pages. Enables DOM manipulation, form validation, and asynchronous requests.

Example: Showing an error message when a form field is left empty.

See also: DOM, HTML, CSS

JWT (JSON Web Token)

Secure Software Architecture Programming for the Web

An open standard for securely transmitting claims between parties as a compact, URL-safe JSON object. Widely used in stateless authentication flows.

Example: After login, the app sends a signed token with each request instead of a password.

↑ Back to Top
K

K-Nearest Neighbour (KNN)

Software Automation

An instance-based algorithm that makes predictions based on the labels of the K most similar training examples in feature space. Simple to implement but computationally expensive for large datasets.

See also: Supervised Learning
↑ Back to Top
L

Linear Regression

Software Automation

A supervised algorithm used to predict a continuous numerical value by fitting a straight line (or hyperplane) to the data. Outputs values on a continuous scale rather than discrete classes.

Example: Predicting an exam score from hours studied.

See also: Logistic Regression, Supervised Learning

Linear Search

Programming Fundamentals

A search algorithm that checks every element in a list sequentially until a match is found or the list ends. Time complexity is O(n), making it slow for large datasets.

Example: Checking each name on a roll, one by one, until you find "Priya".

See also: Binary Search

List

Programming Fundamentals

An ordered collection of items that can grow and shrink as the program runs.

Example: names.append("Priya")

Logic Error

Programming Fundamentals SDLC

An error that causes a program to operate incorrectly or produce wrong output without crashing. The code is syntactically correct, but the algorithm or logic is flawed.

Example: Using < instead of <=, so a mark of exactly 50 fails.

See also: Syntax Error, Debugging

Logistic Regression

Software Automation

A classification algorithm that outputs the probability (between 0 and 1) of an input belonging to a specific class. Outputs are squashed to a range via the sigmoid function.

Example: Predicting the probability that an email is spam.

See also: Linear Regression, Supervised Learning

M

Machine-Readable Data

Programming for the Web

Data in a structured format that software can process automatically.

Example: Event details in JSON-LD so search engines can show dates and venues.

Maintenance

SDLC Software Engineering Project

The ongoing SDLC phase involving patching bugs, fixing security issues, and adding new features after software is deployed to production.

Example: Releasing version 1.1 to fix a bug reported after launch.

Manipulator

Programming Mechatronics

The parts of a mechatronic system (such as robotic grippers or arms) that physically interact with objects in the environment.

Example: A two-finger gripper that picks up blocks.

See also: Actuator, Degrees of Freedom

Manifest

Programming for the Web

A JSON file (manifest.json) that defines a PWA's name, icons, theme colours, and installation settings for adding to a user's home screen.

Example: {"name": "Canteen App", "start_url": "/"}

See also: Progressive Web App

Mechatronics

Programming Mechatronics

An interdisciplinary field integrating mechanical, electrical, and software engineering to design intelligent systems, robotics, and embedded devices.

Example: An automatic irrigation system combining a moisture sensor, pump and control code.

Memory Management

Secure Software Architecture

Controlling how a program uses memory so it runs efficiently and cannot be exploited, for example through buffer overflows.

Example: Closing files and database connections when they are no longer needed.

Message-Passing

Object-Oriented Paradigm

The process by which objects communicate by calling each other's methods. A fundamental concept in OOP describing object interaction.

Example: cart.add(item): the checkout object sends a message to the cart object.

See also: Method, Object

Metadata

Programming for the Web

Data that describes other data.

Example: A photo's date, camera model and GPS location.

Method

Object-Oriented Paradigm

A function or procedure defined within a class that describes the behaviour of its objects. Methods operate on an object's attributes and can modify its state.

Example: account.withdraw(50)

See also: Attribute, Class

Microcontroller

Programming Mechatronics

An integrated circuit containing a processor, memory, and I/O peripherals on a single chip, used for real-time control of embedded systems.

Example: An Arduino Uno or Raspberry Pi Pico.

See also: Sensor, Actuator

Machine Learning (ML)

Software Automation

A specific subset of AI where systems automatically learn patterns from data and improve performance over time without being explicitly programmed for every scenario.

Example: A model that learns to recognise handwritten digits from thousands of examples.

See also: Artificial Intelligence, MLOps

MLOps

Software Automation

The automated process of designing, training, validating, deploying, and monitoring machine learning models, integrating DevOps principles into the ML lifecycle.

Example: Automatically retraining and redeploying a recommendation model each month.

See also: DevOps, Machine Learning

MVC (Model-View-Controller)

Programming for the Web

An architectural design pattern separating an application into three independent layers: Model (data & logic), View (UI), and Controller (input handling).

Example: Flask routes (controller) fetch data (model) and render a template (view).

See also: Design Pattern

N

Neural Network

Software Automation

A computational model inspired by the brain, composed of layers of interconnected artificial neurons that learn to recognise patterns in data through training.

Example: A network with input, hidden and output layers that classifies photos of animals.

See also: Backpropagation, Machine Learning

Non-Functional Requirements

SDLC Software Engineering Project

Requirements that describe *how well* a system should perform, such as security, usability, performance, reliability, and scalability — as opposed to what it should do.

Example: "Pages must load within 2 seconds."

See also: Functional Requirements

NoSQL Database

Programming for the Web

A schema-free database that stores data in flexible formats like JSON documents, key-value pairs, or wide columns, offering scalability and flexibility over strict consistency.

Example: Storing user profiles as JSON documents in MongoDB.

See also: SQL Database
↑ Back to Top
O

Object

Object-Oriented Paradigm

A specific runtime instance of a class, allocated in memory with its own state (attribute values). Multiple objects can exist from the same class blueprint, each maintaining independent state.

Example: s1 = Student("Ava") creates one student object.

See also: Class, Constructor

Object-Relational Mapping (ORM)

Programming for the Web

A technique that lets programmers work with database tables as objects in their programming language instead of writing SQL.

Example: Student.query.filter_by(year=12) instead of SELECT * FROM student WHERE year = 12.

Observer Pattern

Object-Oriented Paradigm

A design pattern defining a one-to-many dependency so that when one object changes state, its dependents (observers) are automatically notified and updated.

Example: A score display updates automatically whenever the game's score changes.

See also: Design Pattern

Opcode

Programming Mechatronics

The part of a machine code instruction that tells the processor which operation to perform.

Example: ADD or JMP in assembly language.

Open Loop System

Programming Mechatronics

A simple control system that operates on a fixed sequence or timer without using feedback. No mechanism to adjust output if conditions change.

Example: A toaster that heats for a fixed time regardless of how brown the bread is.

See also: Closed Loop System

Open-Source Software

Programming for the Web

Software whose source code is freely available to use, study, change and share under a licence.

Example: Linux, Python and VS Code.

Overfitting

Software Automation

A model error where an algorithm memorises training noise instead of generalising, leading to high accuracy on training data but poor performance on unseen test data.

Example: A model scores 99% on training data but 60% on new data.

See also: Underfitting, Training Set
↑ Back to Top
P

Parameter Passing

Programming Fundamentals

Sending values into a subprogram when it is called so it can work with them.

Example: In calculate_gst(price), the value of price is passed in.

Path Coverage

Programming Fundamentals Software Engineering Project

Testing so that every possible route through the code, such as every branch of each IF, is run at least once.

Example: Test data that makes an IF statement both true and false.

Penetration Testing

Secure Software Architecture

Authorised, realistic simulations of cyber attacks by ethical hackers to identify and exploit vulnerabilities. Provides evidence of real-world exploitability unlike SAST/DAST tools.

Example: A hired ethical hacker tries to break into a school's student portal.

See also: DAST, SAST

Peer Review

SDLC Software Engineering Project

A process where colleagues systematically examine software products (code, documentation) to find defects and ensure adherence to standards before moving to the next stage.

Example: Swapping algorithms with a classmate to check each other's logic.

See also: Code Review

PID Control

Programming Mechatronics

A control loop mechanism (Proportional-Integral-Derivative) that adjusts actuator output based on the error between a setpoint and actual state, enabling smooth, responsive control.

Example: A drone adjusts motor speeds to hold a steady height despite wind.

See also: Closed Loop System

Plain Text

Programming for the Web Secure Software Architecture

Readable data before it is encrypted, or after it is decrypted.

Example: The message "Meet at 3pm" before encryption.

Polling

Programming Mechatronics

A software technique where the CPU constantly checks a status flag to see if an event has occurred, rather than responding to interrupts. Less efficient than interrupts.

Example: A loop that checks if button_pressed() every few milliseconds.

See also: Interrupt

Polymorphism

Object-Oriented Paradigm

The ability for objects of different types to respond to the same method call in their own type-specific way. Achieved through method overriding (runtime) or overloading (compile-time).

Example: shape.area() works for both a Circle and a Square.

See also: Inheritance

Polynomial Regression

Software Automation

A regression model that fits a curve, rather than a straight line, to predict a numeric value.

Example: Predicting a car's braking distance from its speed, which rises faster than a straight line.

Privacy by Design

Secure Software Architecture

An approach that builds privacy into software from the start: proactive, embedded in the design and respectful of users.

Example: A fitness app that stores location data only on the phone unless the user chooses to share it.

Prototype

SDLC Software Engineering Project

An early sample or interactive mock-up built to test a concept or elicit stakeholder requirements. Helps visualise the final system before full development.

Example: A clickable Figma mock-up shown to the client before coding.

Pseudocode

Programming Fundamentals SDLC

A method of describing algorithm logic using capitalised keywords and indentation to show control structures, without language-specific syntax. NESA specifies a standard format for HSC examinations.

Example: IF mark ≥ 50 THEN display "Pass" ENDIF

See also: Algorithm, Flowchart

Progressive Web App (PWA)

Programming for the Web

A web application built with standard technologies (HTML, CSS, JS) that offers a native-app-like experience, including offline functionality, push notifications, and installability.

Example: A news site that can be installed on a phone and read offline.

See also: Service Worker, Manifest

PWM (Pulse Width Modulation)

Programming Mechatronics

A technique for controlling the average voltage delivered to a component by varying the duty cycle of a square wave. Used to control motor speed and LED brightness.

Example: Dimming an LED by switching it on 25% of the time.

See also: H-Bridge, Servo Motor

Q

Quality Assurance (QA)

Software Engineering Project Object-Oriented Paradigm

The planned, ongoing checks that make sure software meets agreed quality criteria and legal requirements.

Example: Agreeing a 2-second load-time target and testing it on every release.

R

Race Condition

Secure Software Architecture

A flaw where the result depends on the timing of two actions happening at once, which attackers can exploit.

Example: Two withdrawals processed at the same moment both see $100 and both succeed.

Record

Programming Fundamentals

A data structure that groups related fields of different types about one item.

Example: A student record with name (string), ID (integer) and enrolled (Boolean).

Recursion

Programming Fundamentals

A programming technique where a function calls itself to solve a problem. Each call reduces the problem to a smaller subproblem until a base case is reached.

Example: factorial(n) = n × factorial(n − 1), stopping at factorial(1) = 1.

See also: Iteration

Reinforcement Learning

Software Automation

A machine learning model where an agent learns through trial and error by receiving rewards or penalties from an environment, improving policy over time.

Example: A game-playing agent earns points for winning and learns better moves.

See also: Machine Learning

Requirements Elicitation

SDLC Software Engineering Project

The process of seeking and capturing requirements of a system from users and stakeholders through interviews, surveys, focus groups, and observation.

Example: Interviewing library staff about how they currently track loans.

REST (Representational State Transfer)

Programming for the Web

An architectural style for designing networked APIs using standard HTTP methods (GET, POST, PUT, DELETE) and stateless communication. The dominant approach for modern web services.

Example: DELETE /api/students/42 removes student 42.

See also: API, HTTP

Robotic Process Automation (RPA)

Software Automation

Software bots that copy what a person does on a computer to complete repetitive, rule-based tasks.

Example: A bot that copies invoice details from emails into an accounting system.

Runtime Error

Programming Fundamentals

An error that occurs while a program is running, often causing it to crash due to impossible operations like division by zero or accessing an out-of-bounds array index.

Example: Dividing by zero when a class has no students.

See also: Syntax Error, Logic Error

S

Sandboxing

Secure Software Architecture

Running code in an isolated environment so it cannot harm the rest of the system.

Example: A browser runs each tab in its own sandbox, so a malicious page cannot read your files.

SAST (Static Application Security Testing)

Secure Software Architecture Software Automation

Security testing conducted on source code, bytecode, or binaries without executing the application (white-box testing). Identifies vulnerabilities early in the SDLC.

Example: A static analysis tool scans Python source code and flags insecure functions such as eval().

See also: DAST, Penetration Testing

Scrum

SDLC Software Engineering Project

A lightweight Agile framework organising development into fixed-length iterations called Sprints (typically 2–4 weeks). Defines roles and ceremonies for iterative delivery.

Example: A daily stand-up, a two-week sprint, and a sprint review with the client.

See also: Agile, Sprint

SDLC (Software Development Life Cycle)

SDLC Software Engineering Project

The structured set of cyclical phases used to plan, design, develop, test, and deliver software. NESA defines four key phases: Defining & Understanding, Planning & Designing, Producing & Implementing, and Testing & Evaluating.

Example: Moving a canteen app from requirements through design, testing and maintenance.

Security by Design

Secure Software Architecture

Building security into software from the first design decisions rather than adding it at the end.

Example: Choosing parameterised queries and role-based access before any code is written.

Selection

Programming Fundamentals

A control structure that evaluates a condition to choose between different execution paths using IF/ELSE or CASE statements.

Example: if age >= 18: print("Adult")

See also: Sequence, Iteration

Semi-Supervised Learning

Software Automation

A machine learning model that uses a small amount of labelled data combined with a large pool of unlabelled data to improve learning efficiency.

Example: Labelling 100 photos by hand, then letting the model label 10,000 more.

See also: Supervised Learning, Unsupervised Learning

Sensor

Programming Mechatronics

An input device that converts physical properties (light, temperature, motion, distance) into electrical signals for a microcontroller to process.

Example: An ultrasonic sensor measuring the distance to a wall.

See also: Actuator, Microcontroller

Sequence

Programming Fundamentals

A control structure where instructions are executed in order, one after another, as they are written.

Example: Read two numbers, add them, then display the total.

See also: Selection, Iteration

Sequential File

Programming Fundamentals

A file whose records are stored and read in order, one after another, from the start.

Example: A CSV log file read line by line.

Service Worker

Programming for the Web

A JavaScript file that runs in the background to handle caching, push notifications, and offline functionality in Progressive Web Apps.

Example: Caching a timetable so it still opens with no signal.

See also: Progressive Web App

Servo Motor

Programming Mechatronics

A motor that provides precise angular control, typically using a PWM signal to set a position between 0 and 180 degrees. Includes built-in feedback control.

Example: Setting a servo to 90° to point a camera straight ahead.

See also: Stepper Motor, PWM

Session Management

Secure Software Architecture

Securely tracking a logged-in user across requests, including creating, protecting and ending their session.

Example: Expiring a session after 15 minutes of inactivity and issuing a new session ID at login.

Side Channel Attack

Secure Software Architecture

An attack that gathers secrets from how a system behaves, such as timing, power use or sound, rather than from its data.

Example: Guessing a password one character at a time by measuring how long each check takes.

Single Line Stepping

Programming Fundamentals

Running a program one line at a time in a debugger to watch exactly what each line does.

Example: Stepping through a loop to see where total goes wrong.

Singleton Pattern

Object-Oriented Paradigm

A design pattern that ensures a class has only one instance and provides a global access point to it. Used for shared resources like database connections.

Example: One shared database connection object used across an app.

See also: Design Pattern

SPI (Serial Peripheral Interface)

Programming Mechatronics

A high-speed, four-wire communication protocol (MOSI, MISO, CLK, CS) used for devices like SD cards and ADCs. Faster than I2C but requires more wires.

Example: Reading data from an SD card module on an Arduino.

See also: I2C, UART

Sprint

Software Engineering Project SDLC

A short, fixed period, usually one to four weeks, in which an Agile team builds and reviews a working piece of software.

Example: A two-week sprint that delivers the login page, followed by a review with the client.

SQL (Relational) Database

Programming for the Web

A database that stores data in structured tables with rows and columns, enforcing relationships between tables using primary and foreign keys.

Example: A Students table linked to an Enrolments table by student_id.

See also: NoSQL Database

SQL Injection

Secure Software Architecture

A vulnerability where malicious SQL statements are inserted into input fields and executed by the database. Prevented via parameterised queries and input validation.

Example: Entering ' OR 1=1 -- into a login box to bypass the password check.

See also: XSS, DAST

SSL/TLS Certificate

Programming for the Web

A digital certificate that proves a website's identity and enables encrypted HTTPS connections.

Example: The certificate that makes a bank's address show a padlock.

Stack

Programming Fundamentals

A last in, first out (LIFO) data structure: items are added (pushed) and removed (popped) from the top.

Example: The undo history in a text editor.

Storyboard

SDLC Software Engineering Project

A sequence of visual layouts used in the Design phase to show the user's journey through a system, screen by screen.

Example: Six sketched screens showing a student booking, paying and receiving a receipt.

See also: Wireframe

Stepper Motor

Programming Mechatronics

A motor that moves in discrete, precise steps rather than continuously, ideal for positioning tasks in 3D printers and CNC machines.

Example: Moving a 3D printer's print head exactly 0.1 mm.

See also: Servo Motor

STRIDE

Secure Software Architecture

A threat modelling framework identifying security risks: Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, and Elevation of Privilege.

Example: Asking "Could someone spoof a teacher's login?" while reviewing a design.

Structure Chart

SDLC Object-Oriented Paradigm

A hierarchical tool showing how a system is divided into modules, functions within those modules, and their relationships. Used extensively in the Design phase.

Example: A "Process Results" module split into "Read Marks", "Calculate Average" and "Print Report".

Stub

Object-Oriented Paradigm Programming Fundamentals

A placeholder subroutine that stands in for code not yet written, so the rest of the program can be tested.

Example: def calculate_tax(pay): return 0 while the real tax rules are still being written.

Supervised Learning

Software Automation

A machine learning model trained on a labelled dataset where both inputs and correct outputs are provided, enabling the model to learn the mapping between them.

Example: Training on house photos labelled with their sale prices.

See also: Unsupervised Learning, Machine Learning

Symmetric Encryption

Secure Software Architecture

A fast encryption method (like AES-256) where the same key is used for both encryption and decryption. Fast but requires secure key distribution.

Example: Encrypting a zip file with AES and sharing the same password with a friend.

See also: Asymmetric Encryption

Syntax Error

Programming Fundamentals

A violation of a programming language's grammar rules that prevents the code from running. Usually flagged by the IDE during compilation.

Example: Forgetting the colon in if x > 5.

See also: Logic Error, Runtime Error

T

TCP/IP

Programming for the Web

The core internet protocols: IP addresses and routes packets; TCP makes sure they all arrive, in order and without errors.

Example: Loading a web page relies on TCP/IP to deliver every packet of the page.

Template Engine

Programming for the Web

A tool that combines an HTML template with data to produce a web page.

Example: Jinja2 filling {{ student.name }} in a Flask page.

Test Set

Software Automation

Data held back entirely until final evaluation to provide an unbiased estimate of real-world model performance. Should never be used during development or hyperparameter tuning.

Example: Keeping 20% of photos aside to measure the finished model's accuracy.

See also: Training Set, Validation Set

TLS (Transport Layer Security)

Secure Software Architecture Programming for the Web

A modern cryptographic protocol that provides secure, encrypted communication over a network. The successor to SSL, used by HTTPS to secure web traffic.

Example: The encryption behind the padlock in a browser address bar.

See also: HTTPS, Symmetric Encryption

Top-Down Design

Programming Fundamentals Object-Oriented Paradigm

Designing a system by starting with the whole problem and breaking it into smaller and smaller parts.

Example: "Run canteen app" → "take orders", "take payments", "print dockets".

Training Set

Software Automation

The portion of a dataset (typically 70–80%) used by an algorithm to learn patterns and adjust weights. The model sees these examples repeatedly during training.

See also: Validation Set, Test Set

Tree

Programming Fundamentals

A hierarchical data structure of nodes, where each node has one parent (except the root) and may have children.

Example: A computer's folder structure.

Two's Complement

Programming Fundamentals

The standard method for representing negative integers in binary by inverting the bits of the positive equivalent and adding one. Enables efficient arithmetic on signed numbers.

Example: −5 in 8 bits: 00000101 → invert to 11111010 → add 1 → 11111011.

See also: Integer

U

UART (Universal Asynchronous Receiver-Transmitter)

Programming Mechatronics

A two-wire serial protocol (TX and RX) that requires no clock signal, used for serial communication between microcontrollers and computers.

Example: An Arduino sending sensor readings to a laptop over USB serial.

See also: I2C, SPI

UML (Unified Modeling Language)

SDLC Object-Oriented Paradigm Software Engineering Project

A standardised visual language for specifying, visualising, constructing, and documenting software systems. HSC-relevant diagrams include Class, Use Case, Sequence, and Activity Diagrams.

Example: A class diagram and a use case diagram for a library system.

See also: Class Diagram, Use Case Diagram

Underfitting

Software Automation

A model error where the algorithm is too simple to learn the underlying patterns in training data, resulting in poor performance on both training and test sets.

Example: Fitting a straight line to data that clearly curves.

See also: Overfitting

Unit Testing

SDLC Software Automation

The practice of testing individual units (functions, methods, classes) in isolation to verify correct behaviour. Foundation of automated test suites and CI/CD.

Example: assert add(2, 3) == 5

See also: CI/CD, UAT

Unit, Subsystem and System Testing

Object-Oriented Paradigm Software Engineering Project

Testing at three levels: single units such as functions, groups of units working together, and the whole system.

Example: Test add_to_cart(), then the checkout subsystem, then a full order from login to receipt.

Unsupervised Learning

Software Automation

A machine learning model that analyses unlabelled data to find hidden patterns or groupings autonomously, without being told what the correct output should be.

Example: Grouping shoppers into clusters by buying habits, with no labels given.

See also: Supervised Learning, Machine Learning

User Acceptance Testing (UAT)

SDLC Software Engineering Project

The final testing phase where actual users test the software in real-world scenarios to ensure it meets requirements and is ready for production deployment.

Example: The canteen manager tries the finished ordering app before it goes live.

Use Case Diagram

SDLC Software Engineering Project

A UML diagram representing interactions between users (actors) and the system to achieve specific goals (use cases). Helps define system scope and requirements.

Example: A "Student" actor linked to "Borrow Book" and "Return Book".

See also: UML, Functional Requirements

User Stories

SDLC Software Engineering Project

Requirement statements written from an end-user's perspective in the format: "As a [role], I want [feature] so that [benefit]." Core to Agile development.

Example: "As a student, I want to see my timetable so that I know where to go."

See also: Acceptance Criteria, Agile

V

Validation Set

Software Automation

Data used during development to tune hyperparameters and compare different model configurations. Separate from training data but evaluated during development, unlike the test set.

Example: Comparing models with 3, 5 and 7 layers on held-out data before the final test.

See also: Training Set, Test Set

Variable

Programming Fundamentals

A named location in memory used to store data that can change during program execution. Variables have names, types, and scope.

Example: score = 0

See also: Array, Data Dictionary

Version Control (Git)

SDLC Software Engineering Project

A system that tracks every change to code, allowing developers to revert to previous states, create branches, and collaborate safely. Git is the industry standard.

Example: git commit -m "Add login page" saves a snapshot you can return to.

See also: Code Review

Virtual Personal Assistant

Software Automation

Software that uses speech recognition and ML to understand requests and carry out tasks.

Example: Asking Siri to set a timer.

Vulnerability Assessment

Secure Software Architecture

A systematic review that finds, ranks and reports security weaknesses in a system.

Example: A scanner reports an outdated library with a known exploit and rates it high risk.

W

Watch

Programming Fundamentals

A debugger feature that shows the value of a chosen variable or expression as the program runs.

Example: Watching len(queue) to see when the queue empties.

Waterfall

SDLC Software Engineering Project

A linear, sequential development approach where each phase (requirements, design, implementation, testing) must be completed before the next begins. Best suited for large projects with fixed, well-understood requirements.

Example: Finishing and signing off the full design before any code is written.

See also: Agile, SDLC

Web Accessibility (WCAG)

Programming for the Web

International guidelines developed by the W3C to make web content usable for people with various disabilities. Covers visual, hearing, motor, and cognitive disabilities.

Example: Adding alt text so a screen reader can describe an image.

Wireframe

SDLC Software Engineering Project

A low-fidelity layout sketch of a single screen showing the placement of UI elements (buttons, text fields, navigation). Created early in Design phase before detailed visual design.

Example: A grey-box sketch showing where the logo, menu and search bar go.

See also: Prototype, Storyboard

White-Box Testing

SDLC Software Automation

A testing technique where the tester has full knowledge of internal code structure and logic. Designs tests to cover all branches, paths, and conditions — maximising code coverage.

Example: Writing tests that make every IF statement take both its true and false paths.

See also: Black-Box Testing, SAST

WAGILE

SDLC

A hybrid of Waterfall and Agile where high-level phases are planned in advance, but internal development is iterative. Pragmatic approach balancing both methodologies.

Example: A fixed-date project with a planned design phase, then Agile sprints for development.

See also: Agile, Waterfall

World Wide Web Consortium (W3C)

Programming for the Web

The international organisation that develops standards for the web, such as HTML, CSS and WCAG.

Example: WCAG accessibility guidelines are published by the W3C's Web Accessibility Initiative.

XSS (Cross-Site Scripting)

Secure Software Architecture

A vulnerability where an attacker injects malicious client-side scripts into web pages viewed by other users. Caused by improper input validation and output encoding.

Example: A comment containing <script> that runs in every reader's browser.

See also: CSRF, SQL Injection
