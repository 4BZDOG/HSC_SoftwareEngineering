3

3-2-1 Backup Rule

A guideline to keep three copies of data, on two different kinds of storage, with one copy off-site.

Example: Working copy on a laptop, a second copy on an external drive and a third copy in cloud storage.

A

Abstract Class

A class that cannot be instantiated directly and exists purely to be subclassed. Abstract classes often define method signatures that subclasses must implement, enforcing a consistent interface across a family of types.

Example: A Shape class declares area() but only Circle and Square subclasses can be created.

See also: Class, Inheritance

Abstraction

The concept of hiding complex internal implementation details while exposing only the necessary interface to the user or calling code. Reduces cognitive complexity and increases maintainability.

Example: Calling send_email(to, body) without knowing how the mail server connection works.

See also: Encapsulation

Acceleration Ramping

Limiting how much a motor command may change on each loop, so speed rises gradually.

Example: Raising motor speed by at most 10% per loop to avoid wheel slip and current surges.

Acceptance Criteria

Specific, measurable conditions that must be met to confirm a user story has been implemented correctly. They provide a clear definition of "done" for each requirement.

Example: "Given a wrong password three times, the account locks for 15 minutes."

See also: User Stories, UAT

Access Control

Rules and mechanisms that decide which users can view or change which resources.

Example: Only teachers can edit marks; students can only view their own.

Access Modifier

Keywords (such as public, private, and protected) that control the visibility and accessibility of class members. They enforce encapsulation by restricting which parts of a program can access specific attributes or methods.

Example: Marking balance as private so only deposit() and withdraw() can change it.

See also: Encapsulation

Accountability

The principle of tracing every action back to a specific authenticated user through immutable audit logs. Ensures that no action can be performed anonymously within a secure system.

Example: An audit log records that user jchen deleted invoice #204 at 10:14 am.

See also: Authentication, Authorisation

Accuracy

The proportion of a model's predictions that are correct.

Example: 90 correct out of 100 test images is 90% accuracy.

Activation Function

A function applied to a neuron's output that adds non-linearity, so the network can learn complex patterns.

Example: ReLU turns negative values into 0.

Actuator

An output component that converts electrical energy into physical motion, such as a motor, solenoid, or pneumatic piston. Actuators enable a mechatronic system to interact with the physical world.

Example: A servo motor that opens a greenhouse vent when the temperature rises.

See also: Sensor, Servo Motor

Adaptive Bitrate Streaming

A streaming method in which the player switches between quality levels of short video segments according to the speed of the connection.

Example: The picture softens on a slow connection instead of stopping to buffer.

ADC (Analog-to-Digital Converter)

A component that samples continuous analog voltages and converts them into discrete digital numbers for processing by a microcontroller. Resolution is measured in bits (e.g., a 10-bit ADC yields 1024 distinct values).

Example: An Arduino reading a light sensor as a number from 0 to 1023.

Address Register

A small, fast storage location inside a processor that holds the memory address of data or of the next instruction to fetch.

Example: While running a loop, the program counter (an address register) points to the next instruction in flash memory.

AES (Advanced Encryption Standard)

A widely used symmetric encryption algorithm, often with 256-bit keys, for protecting stored and transmitted data.

Example: Full-disk encryption on a laptop uses AES-256.

Aggregate Function

A SQL function such as SUM, AVG, COUNT, MAX or MIN that calculates one value from many rows, often for each group.

Example: AVG(Games.Cost) with GROUP BY publisher gives each publisher's average price.

Agile Methodology

An iterative and incremental approach to software development focusing on flexibility, responsiveness to change, and frequent client feedback. Agile prioritises working software and customer collaboration over rigid upfront specification.

Example: A team releases a school canteen app in two-week sprints, changing features after student feedback.

See also: Scrum, WAGILE, Sprint

Allowlist

A validation rule that states exactly which values or characters are acceptable and rejects everything else.

Example: A username must match [A-Za-z0-9_]{3,20}; any other character causes rejection.

Anti-Windup

A safeguard that stops a PID controller's integral term growing while the actuator is at its limit.

Example: Stopping the integral sum while the vent is fully open so the controller does not overshoot when the weather changes.

API Contract

An agreed description of an API's URLs, methods, parameters and response formats that front-end and back-end developers both build to.

Example: An OpenAPI file states that GET /games needs max_cost and returns a list of names and costs.

API Key

A secret code that identifies a program calling an API and controls its access; it must never be published in client-side code or a public repository.

Example: Storing a weather API key in an environment variable instead of the source code.

App

NESA

A software program designed for a specific purpose to run on mobile devices or on a personal computer. An abbreviation of the word ‘application’.

Example: A canteen ordering app on a phone that lets students pre-order their lunch.

Artificial Intelligence (AI)

NESA

Intelligence demonstrated by machines. Sometimes called machine intelligence.

Example: A chatbot that answers enrolment questions on a school website.

See also: Machine Learning, Neural Network

Algorithm

NESA

A step-by-step procedure required to solve a problem. Algorithms may be presented in many ways, e.g. written instructions, flow charts or using a computer programming language.

Example: The steps to find the largest mark in a class list.

See also: Pseudocode, Flowchart

API (Application Programming Interface)

NESA

An interface that allows an application or website to plug into another program or website.

Example: A weather app requests GET /forecast?city=Sydney from the Bureau of Meteorology's servers.

See also: REST

Array

A data structure consisting of a collection of elements identified by at least one index or key, stored in contiguous memory locations. Arrays provide O(1) access by index.

Example: marks = [72, 85, 64], where marks[1] is 85.

See also: Variable

ASCII

A 7-bit character encoding for 128 characters, including English letters, digits and punctuation.

Example: "A" is 65 in ASCII.

Assertion

A statement that a condition must be true at that point in a program; if it is false the program raises an error, which is how simple tests report failure.

Example: assert member.loan_count == 3 fails with AssertionError if the count is wrong.

Assets

NESA

Assets are the digital elements that can be used or incorporated into a multimedia presentation or production. They include graphics, photographs, videos, audio, animations or other artistic data.

Example: The logo, photographs and a short intro video used on a school open-day web page.

Asymmetric Encryption

An encryption method using a mathematically linked public and private key pair. The public key encrypts data (or verifies signatures), while only the corresponding private key can decrypt (or sign). Used for secure key exchange and digital signatures.

Example: A browser encrypts a session key with a bank's public key; only the bank's private key can read it.

See also: Symmetric Encryption, Digital Signature

Attack Surface

The total number of possible ways an attacker can interact with or compromise a software system. Minimising the attack surface — by reducing exposed endpoints, disabling unused features, and enforcing least privilege — is a core security principle.

Example: Closing an unused admin login page removes one way in for attackers.

Attack Vector

The path or method an attacker uses to reach a system, such as email, a web form or an unpatched service.

Example: Phishing emails are the most common attack vector for ransomware.

Attribute

A data element or property defined within a class that stores the state of an object. For example, a Car class might have attributes like colour, speed, and fuel_level.

See also: Method, Class

Audit Trail

A secure, time-stamped log of who did what in a system, used to detect misuse and investigate incidents.

Example: A log showing which staff member changed a student's mark and when.

Australia's AI Ethics Principles

Eight voluntary principles published by the Australian Government in 2019 to guide the design, development and use of AI.

Example: Fairness and contestability are two of the eight.

Australian Privacy Principles

The 13 principles in the Privacy Act 1988 that set out how organisations must handle personal information, from collection to security and access.

Example: APP 11 requires reasonable steps to protect personal information from misuse and unauthorised access.

Authentication

The process of verifying the identity of a user or system, often using passwords, biometrics, or multi-factor authentication (MFA). Answers the question: "Who are you?"

Example: Logging in with a password plus a code from an authenticator app.

See also: Authorisation, JWT

Authorisation

The process of determining what an authenticated user is permitted to do, based on the principle of least privilege. Answers the question: "What are you allowed to do?"

Example: A student can view their own results but only a teacher can edit them.

See also: Authentication, Accountability

Automation Bias

The human tendency to trust an automated suggestion and stop checking it.

Example: An operator accepts a wrong alert because the system is usually right.

Availability

Ensuring that systems and data remain operational and accessible to authorised users when needed. One of the three pillars of the CIA triad alongside Confidentiality and Integrity.

Example: A school portal stays online during exam results release despite heavy traffic.

See also: Confidentiality, Integrity

B

Backlog (Product Backlog)

A prioritised list of all features, user stories, and bug fixes yet to be completed for a product. In Scrum, the Product Backlog is the single source of work for the development team.

Example: "Add dark mode" sits in the backlog below the higher-priority "Fix login bug".

See also: Scrum, Sprint

Backpropagation

The training process where prediction error is propagated backwards through a neural network to adjust connection weights using gradient descent. This iterative process minimises the loss function over many epochs.

Example: After predicting "cat" for a dog photo, the network nudges its weights to reduce that error.

See also: Neural Network, Overfitting

Back-end

The server-side portion of a web application responsible for business logic, database queries, authentication, and security enforcement. Users never interact with back-end code directly.

Example: The Flask server code that checks a login and queries the database.

See also: Front-end Framework, REST

Backtracking

An algorithm design strategy that builds a solution step by step and, when a step leads to a dead end, undoes it and tries a different choice.

Example: Solving a maze by following a path until it is blocked, then stepping back to the last junction and trying another way.

Backup

A copy of data kept separately so it can be restored if the original is lost, damaged or encrypted by ransomware.

Example: The 3-2-1 rule: three copies, on two kinds of media, one off-site.

Bandwidth

The maximum amount of data a network connection can carry per second.

Example: A 100 Mbps home connection.

Base Case

The condition in a recursive function that stops further recursive calls by returning a result directly.

Example: In binary search, low greater than high returns -1 without another call.

bcrypt

A deliberately slow password-hashing function that adds a salt automatically, making brute-force and rainbow table attacks impractical.

Example: bcrypt.hashpw(password, bcrypt.gensalt())

Beta Testing

Testing a nearly finished product with real users outside the development team before release.

Example: Letting one class use the new app for a week and collecting feedback.

Bias

Systematic unfairness in data or a model that produces worse results for some groups of people.

Example: A face-recognition model trained mostly on light-skinned faces performing poorly on darker skin.

Big Data

NESA

Extremely large datasets that may be analysed computationally to reveal patterns, trends and associations.

Example: Every song played by every Spotify user each day.

Bill of Materials

A list of every part in a build, with quantities and costs.

Example: A greenhouse controller's list of the board, sensors, servo, pump, driver and supplies.

Binary

A base-2 number system that uses only the digits 0 and 1, matching the two states of computer hardware.

Example: 1011 in binary is 8 + 2 + 1 = 11 in decimal.

Binary Search

An efficient algorithm that finds an item in a sorted list by repeatedly dividing the search interval in half. It has a time complexity of O(log n), making it far faster than linear search for large datasets.

Example: Finding 21 in [3, 5, 8, 12, 17, 21, 26, 30] in two comparisons by halving the list.

See also: Linear Search

Bit

A single binary digit, 0 or 1, the smallest unit of data a computer stores.

Example: The pattern 1011 is four bits.

Black-Box Testing

NESA

A testing technique where there is no knowledge of the internal workings of an application. A user will provide inputs and observe the outputs in order to determine functionality of the program.

Example: Entering valid, boundary and invalid marks into a grading program and checking the grades it returns.

Blast Radius

How much of a system or how much data is affected if one component is compromised.

Example: A least-privilege database account keeps the blast radius of an SQL injection to one table.

Boolean

A logical data type that represents one of two values: True or False. Booleans are fundamental to control flow, conditions, and logical expressions in every programming language.

Example: is_logged_in = True

See also: Selection

Bottom-Up Design

Designing a system by first building and testing small, reusable components, then combining them into larger parts.

Example: Writing and testing validate_email() and hash_password() before building the registration page that uses them.

Boundary Value

Test data at, just inside and just outside the limits of a valid range, where off-by-one errors are most likely.

Example: For marks from 0 to 100: −1, 0, 1, 99, 100 and 101.

Box Model

The way CSS treats every element as a box made of content, padding, border and margin.

Example: A 200px wide box with 10px padding and a 2px border is 224px wide before margins.

Branching

In version control, creating a separate line of development so work can happen without affecting the main code.

Example: A feature/login branch that is merged into main when finished.

Breakpoint

A marker set in an IDE that pauses a program at a chosen line so the programmer can inspect variables.

Example: Pausing at the line total += price to check the value of price on each loop.

Broken Object-Level Authorisation

An API flaw where the server does not check that the caller may access the specific record requested.

Example: Changing /students/12/marks to /students/13/marks returns another student's marks.

Brownout

A temporary drop in supply voltage that can reset a microcontroller or make it behave unpredictably.

Example: A servo starting up draws a large current and pulls the shared 5 V supply low, resetting the controller.

Bubble Sort

A simple sorting algorithm that repeatedly swaps neighbouring items that are in the wrong order until the list is sorted.

Example: Sorting [5, 2, 4] → [2, 5, 4] → [2, 4, 5].

Buffer Overflow

A flaw where a program writes more data into a block of memory than it can hold, overwriting nearby memory, which attackers can exploit.

Example: Copying a 300-character name into a 256-byte buffer without checking its length.

Business Continuity

Planning so an organisation can keep its essential services running during and after a disruption.

Example: A bank switching to a standby system so customers can still pay during an outage.

Business Process Automation (BPA)

Using software to automate a complete business workflow across people and systems, not just single tasks.

Example: A leave request that is submitted online, approved by a manager and updated in payroll without any paperwork.

Byte

A group of eight bits, able to hold 256 different values.

Example: One byte can store 0 to 255, or FF in hexadecimal.

C

Cache-Control

An HTTP header that tells browsers and caches how long they may reuse a response.

Example: Cache-Control: max-age=31536000, immutable lets a fingerprinted file be reused for a year.

Cache-First Strategy

A service worker strategy that answers from the cache and only uses the network when the file is not cached.

Example: The app shell is served from the cache so it opens instantly and offline.

Caching

Storing the result of an expensive operation so that later requests can reuse it instead of repeating the work.

Example: A Report object calculates its average once and reuses the stored value.

Calibration

Comparing a sensor with a known reference and correcting its readings to match.

Example: Measuring a temperature sensor in ice water and boiling water and adjusting its readings to 0 and 100 °C.

Call Stack

The record of the functions that are currently running, with the most recent call on top, removed as each returns.

Example: A recursive maze search adds one entry for every square it enters.

Cartesian Product

The result of pairing every row of one table with every row of another, which happens when a join condition is left out.

Example: Joining Games, Publishers and Developers without conditions returns 7 x 3 x 4 = 84 rows.

CDN (Content Delivery Network)

A geographically distributed network of servers that caches and serves static assets (images, CSS, JS) from locations close to the user, reducing latency and improving load times.

Example: A video site serves Sydney users from a Sydney server instead of one in the USA.

Certificate Authority (CA)

A trusted organisation that verifies who controls a domain and signs a digital certificate to prove it.

Example: A browser trusts a certificate because it chains up to a CA whose root certificate is built into the browser.

Chain of Trust

The sequence of signed certificates from a website's certificate through intermediate authorities to a trusted root certificate.

Example: The browser follows each signature from gameshelf.example up to a root it already trusts.

CI/CD (Continuous Integration / Continuous Deployment)

A DevOps practice where code changes are automatically built, tested (CI) and deployed to staging or production environments (CD). Enables rapid, reliable delivery cycles with minimal manual intervention.

Example: Every push to GitHub runs the tests automatically and deploys if they pass.

See also: DevOps

Cipher Suite

The combination of algorithms a TLS connection uses for key exchange, encryption and integrity checking.

Example: A ClientHello lists the cipher suites the browser supports and the server picks one.

Cipher Text

Data after encryption, which is unreadable without the correct key.

Example: "Hello" encrypted with AES might become 9f2c4e….

Class

A blueprint or template defining the structure (attributes) and behaviour (methods) for a family of objects. Instantiation creates an individual Object from the class definition in memory.

Example: A Student class defines a name, ID and enrol() method.

See also: Object, Inheritance, Class Diagram

Class Attribute

An attribute defined in the class body and shared by every object of that class, as opposed to an instance attribute that belongs to one object.

Example: Member.MAX_LOANS = 3 applies to every member.

Class Diagram

A UML diagram that represents classes, their attributes, methods, and the relationships (inheritance, composition, association) between them. A key deliverable in the Design phase of OOP projects.

Example: A box for Book listing title, isbn and borrow(), linked to Library.

See also: UML, Class

Classification

A machine learning task that predicts which category an input belongs to.

Example: Predicting whether an email is spam or not spam.

Closed Loop System

A control system that uses sensor feedback to continuously adjust its output in real-time. The feedback loop allows the system to self-correct and maintain a desired state despite disturbances.

Example: A robot vacuum uses a bump sensor to change direction when it hits a wall.

See also: Open Loop System, PID Control

Clustering

An unsupervised learning task that groups similar data points without labels.

Example: Grouping customers by their buying habits.

Code Review

A systematic peer examination of source code to find defects, ensure adherence to coding standards, and share knowledge before merging changes into the main codebase.

Example: A teammate spots a missing input check before a pull request is merged.

See also: Version Control

Cohesion

A measure of how closely related the responsibilities of a single module or class are. High cohesion (single-responsibility) is a hallmark of good design — each unit does one thing well.

Example: A ReportPrinter class that only formats and prints reports (high cohesion).

See also: Coupling

Collaborate

NESA

Working with others towards a shared goal, through a variety of modes of communication. This may be achieved using a range of technologies, tools and processes.

Example: Four students share a Git repository, meet in a daily stand-up and review each other's pull requests to finish one project.

Collision

The situation where two different keys are given the same slot by a hash function.

Example: The keys Ava and Dev both map to slot 0 in the toy hash function.

Compiler

A program that translates the whole of a program's source code into machine code before it runs.

Example: Arduino code is compiled before being uploaded to the board.

Composition

A strong "has-a" relationship where parts cannot exist independently of the whole. For example, a Room cannot exist without a Building. Contrasts with aggregation, where parts can exist independently.

See also: Inheritance, Class Diagram

Computational Thinking

NESA

A process in which a problem is analysed and solved so that a human, machine or computer can effectively implement the solution. It involves using strategies to organise data logically, break down problems into parts, interpret patterns and design, and implement algorithms to solve problems.

Example: Breaking "run the school canteen online" into ordering, paying and preparing, each solved separately.

Computer Vision

The branch of AI that lets computers interpret images and video.

Example: A self-driving car recognising stop signs.

Confidentiality

Ensuring that sensitive data is accessible only to authorised entities through encryption and access controls. One of the three pillars of the CIA triad.

Example: Encrypting medical records so only the patient's doctor can read them.

See also: Integrity, Availability

Confusion Matrix

A table summarising prediction results for a classification model, showing counts of True Positives, True Negatives, False Positives, and False Negatives. Used to calculate metrics like accuracy, precision, and recall.

Example: A spam filter with 90 true positives, 5 false positives, 8 false negatives and 97 true negatives.

Constant-Time Comparison

A comparison that takes the same time wherever two values differ, so timing cannot leak how much of a guess was correct.

Example: hmac.compare_digest(a, b) instead of a == b when checking a token.

Constraint

A limit on how a project may be carried out, such as time, budget, skills, technology, law or policy.

Example: The project must be finished in seven weeks using free tools.

Constructor

A special method (such as __init__ in Python or the class-named method in Java) that initialises an object's state when it is first created. Constructors set default attribute values and perform setup logic.

Example: def __init__(self, name): self.name = name

See also: Class, Object

Content Management System (CMS)

Software that lets people create, edit and publish web content through an interface rather than by writing code.

Example: Teachers posting school news in WordPress.

Content Security Policy (CSP)

An HTTP header that tells the browser which sources of scripts, styles and images a page may load, limiting the damage of XSS.

Example: Content-Security-Policy: script-src 'self'

Contestability

The principle that people affected by a significant AI decision can challenge it through an accessible process.

Example: A person refused a service can ask for a human to review the decision.

Contingency

Extra time or money added to an estimate to cover tasks that take longer than expected or problems that arise.

Example: Adding 15% contingency to a 42-hour estimate gives 48.3 hours.

Contract Test

An automated test that checks a real API still matches its agreed contract.

Example: A test fails when the back end renames Cost to Price.

Contrast Ratio

A number from 1:1 to 21:1 comparing the brightness of text and its background, used by WCAG to test readability.

Example: WCAG AA requires at least 4.5:1 for normal text, so #999999 on white (2.85:1) fails.

Cookie

A small piece of data a website stores in the browser and receives back with each request, often used to keep a user logged in.

Example: A session cookie marked HttpOnly; Secure; SameSite=Strict.

Copyleft

A licensing approach that lets others modify and share software only if they release their versions under the same terms.

Example: The GPL requires a distributed program that includes GPL code to be released with its source under the GPL.

Copyright

The legal right of creators to control how their original work, including source code, is copied and used.

Example: Reusing code from a tutorial only as its licence allows, and crediting the author.

Core Web Vitals

Google's measures of real-world page experience: loading (LCP), responsiveness (INP) and visual stability (CLS).

Example: Setting width and height on images reduces layout shift, improving CLS.

Correlation ID

A random reference that links the short error message a user sees to the detailed entry in the internal log.

Example: The error page says 'Quote reference 5c4d6f38'; support finds that reference in the log.

CORS (Cross-Origin Resource Sharing)

A browser security mechanism that uses HTTP headers to permit or restrict resource requests from different origins. Prevents malicious websites from making unauthorised API calls on behalf of users.

Example: A server allows requests from myschool.edu.au but blocks scripts from other sites.

See also: CSRF, HTTPS

Coupling

The degree of interdependence between software modules. Loose coupling — minimising direct knowledge between modules — improves maintainability, testability, and security isolation.

Example: A login module that calls a shared UserService rather than reading the database directly (loose coupling).

See also: Cohesion

Critical Path

The longest chain of dependent tasks in a schedule, which decides the earliest date the project can finish.

Example: In the Library Loans plan, tasks A, B, C, F, G, H and J form a 32-day critical path.

Cryptography

The use of mathematical techniques such as encryption, hashing and digital signatures to protect data and verify identity.

Example: Encrypting stored credit card numbers and hashing passwords.

CSRF (Cross-Site Request Forgery)

An attack that tricks an authenticated user's browser into submitting unwanted requests to another website. Mitigated by anti-CSRF tokens, SameSite cookies, and validating the request origin.

Example: A hidden form on a malicious page makes a logged-in user's browser transfer money.

See also: XSS, CORS

CSS (Cascading Style Sheets)

A stylesheet language used to describe the visual presentation and layout of HTML documents. CSS controls colours, fonts, spacing, responsive breakpoints, and animations.

Example: h1 { color: navy; } makes every main heading navy.

See also: HTML, JavaScript

CSS Cascade

The rules a browser uses to choose between conflicting CSS declarations: importance first, then specificity (an inline style counts as the most specific), then source order.

Example: With two rules of equal specificity, the one later in the style sheet is applied.

CSS Preprocessor

A tool such as Sass that adds variables and nesting to CSS and compiles to standard CSS.

Example: An SCSS file with a $brand variable compiles to CSS with the colour written out.

CSS Specificity

A measure of how precisely a CSS selector targets an element, written as counts of IDs, classes and elements, used to decide which rule wins.

Example: #welcome is (1, 0, 0) and p.red-text is (0, 1, 1), so the ID rule wins.

CVE

A public identifier for a specific known security vulnerability in software, used to track and fix it.

Example: A vulnerability scanner reports that a library has a published CVE fixed in a newer version.

CVSS

The Common Vulnerability Scoring System, a 0.0 to 10.0 rating of how severe a vulnerability is, with bands from Low to Critical.

Example: A score of 9.8 is rated Critical and is fixed before a 5.3 Medium finding.

Cyber Security Act 2024

An Australian Act that includes ransomware payment reporting for certain organisations, security standards for smart devices and a Cyber Incident Review Board.

Example: A covered business that pays a ransomware demand must report the payment to the government.

Cybercrime Act 2001

An Australian Act that added computer offences, including unauthorised access to or modification of data, to the Criminal Code.

Example: A penetration tester needs written authorisation because unauthorised access is an offence.

D

Dark Pattern

A user interface design that manipulates people into choices they would not otherwise make, such as hiding privacy controls.

Example: A tiny grey 'Reject all' button beside a large bright 'Accept all' button.

DAST (Dynamic Application Security Testing)

Security testing performed against a running application from the outside — simulating the perspective of an attacker. Identifies vulnerabilities such as SQL injection and XSS at runtime.

Example: Running an automated scanner against a live test site to find XSS vulnerabilities.

See also: SAST, Penetration Testing

Data

NESA

A discrete representation of information using number codes. Data may include characters (e.g. alphabetic letters, numbers and symbols), images, sounds and/or instructions that, when represented by number codes, can be manipulated, stored and communicated by digital systems. For example, characters may be represented using ASCII code or images may be represented by a bitmap of numbers representing each ‘dot’ or pixel.

Example: The number 65 stored for the letter A in ASCII, or a red pixel stored as the numbers 255, 0 and 0.

Data at Rest

Data stored on a disk, in a database or in a backup rather than moving across a network.

Example: Customer records stored in an encrypted database.

Data Breach

An incident where personal or confidential data is accessed, disclosed or lost without authorisation.

Example: Millions of customer records published online after a cyber attack.

Data Dictionary

A metadata tool that documents every variable's name, data type, size, description, and validation rules. Essential for the Design and Implementation phases of the SDLC.

Example: student_id | integer | 8 digits | unique ID for each student.

Data Drift

A change in the data a deployed model receives, so that it no longer resembles the training data and accuracy falls.

Example: A courier's delivery-time model becomes less accurate after deliveries begin in new suburbs.

Data Flow Diagram (DFD)

A diagram showing how data moves between external entities, processes and data stores in a system.

Example: A student enters login details → "Verify login" process → reads the Users data store.

Data in Transit

Servo Motor

A motor that provides precise angular control, typically using a PWM signal to set a position between 0 and 180 degrees. Includes built-in feedback control.

Example: Setting a servo to 90° to point a camera straight ahead.

See also: Stepper Motor, PWM

Session Fixation

An attack in which the attacker makes a victim use a session ID the attacker already knows, then takes over the session after the victim logs in.

Example: Issuing a new session ID at login makes a pre-login ID planted by an attacker useless.

Session Key

A temporary symmetric key agreed during the TLS handshake and used to encrypt the data of one connection.

Example: After the handshake, the browser and server encrypt every request and response with the session key.

Session Management

Securely tracking a logged-in user across requests, including creating, protecting and ending their session.

Example: Expiring a session after 15 minutes of inactivity and issuing a new session ID at login.

Setpoint

The target value that a control system tries to hold.

Example: A greenhouse controller with a setpoint of 26 °C opens the vent when the measured temperature rises above it.

Side Channel Attack

An attack that gathers secrets from how a system behaves, such as timing, power use or sound, rather than from its data.

Example: Guessing a password one character at a time by measuring how long each check takes.

Sigmoid Function

A curve that squashes any number into a value between 0 and 1, used to turn a weighted sum into a probability.

Example: The sigmoid of 0 is 0.5 and the sigmoid of 4 is about 0.98.

Sign Bit

The left-hand bit of a two's complement number, which is 1 for negative numbers and 0 for zero and positive numbers.

Example: In 8-bit 11111011 the sign bit is 1, so the value is negative.

Simulated Data

Made-up data that imitates real data, used for testing when real data is unavailable or unsafe to use.

Example: Generating 500 pretend canteen orders, including extreme values.

Single Line Stepping

Running a program one line at a time in a debugger to watch exactly what each line does.

Example: Stepping through a loop to see where total goes wrong.

Single Precision

A 32-bit floating point format with 1 sign bit, 8 exponent bits and 23 fraction bits, giving about seven significant digits.

Example: Storing 16777217 in single precision gives 16777216.0.

Single Responsibility Principle

The guideline that each class or method should have one job and one reason to change.

Example: A receipt method only formats a receipt; it does not also record the loan.

Singleton Pattern

A design pattern that ensures a class has only one instance and provides a global access point to it. Used for shared resources like database connections.

Example: One shared database connection object used across an app.

See also: Design Pattern

Specialisation

Creating a more specific subclass from an existing class, the opposite direction to generalisation.

Example: Adding AudioBook as a subclass of Book.

SPI (Serial Peripheral Interface)

A high-speed, four-wire communication protocol (MOSI, MISO, CLK, CS) used for devices like SD cards and ADCs. Faster than I2C but requires more wires.

Example: Reading data from an SD card module on an Arduino.

See also: I2C, UART

Sprint

A short, fixed period, usually one to four weeks, in which an Agile team builds and reviews a working piece of software.

Example: A two-week sprint that delivers the login page, followed by a review with the client.

SQL (Relational) Database

A database that stores data in structured tables with rows and columns, enforcing relationships between tables using primary and foreign keys.

Example: A Students table linked to an Enrolments table by student_id.

See also: NoSQL Database

SQL Injection

A vulnerability where malicious SQL statements are inserted into input fields and executed by the database. Prevented via parameterised queries and input validation.

Example: Entering ' OR 1=1 -- into a login box to bypass the password check.

See also: XSS, DAST

SQLite

A small, self-contained SQL database stored in a single file, built into Python.

Example: A Flask project storing its data in app.db.

SSL/TLS Certificate

A digital certificate that proves a website's identity and enables encrypted HTTPS connections.

Example: The certificate that makes a bank's address show a padlock.

Stack

A last in, first out (LIFO) data structure: items are added (pushed) and removed (popped) from the top.

Example: The undo history in a text editor.

Stakeholder

Anyone affected by, or with an interest in, a software project, such as clients, users, developers and managers.

Example: Students, teachers and parents are all stakeholders in a school app.

Stand-up Meeting

A short daily Agile meeting where each team member says what they did, what they will do and what is blocking them.

Example: A 15-minute meeting at 9 am, standing up to keep it short.

Steady-State Error

The difference between the setpoint and the value a control system settles at after it has stopped changing.

Example: A proportional-only vent controller that settles at 28.4 °C against a 26 °C setpoint has a steady-state error of 2.4 °C.

Stepwise Refinement

Developing an algorithm in levels, starting with a general mainline and adding detail to each named subroutine.

Example: The mainline calls GetOrder, and GetOrder is refined into its own algorithm.

Stored XSS

A cross-site scripting attack in which the malicious input is saved by the server and delivered to every user who views it.

Example: An attacker posts a comment containing a script and every visitor who loads the comments runs it.

Story Points

A relative measure of the effort a user story needs, used to plan and forecast work in an Agile project.

Example: Issuing a loan is sized at 5 points and refusing a loan at the limit at 3.

Storyboard

A sequence of visual layouts used in the Design phase to show the user's journey through a system, screen by screen.

Example: Six sketched screens showing a student booking, paying and receiving a receipt.

See also: Wireframe

Stepper Motor

A motor that moves in discrete, precise steps rather than continuously, ideal for positioning tasks in 3D printers and CNC machines.

Example: Moving a 3D printer's print head exactly 0.1 mm.

See also: Servo Motor

STRIDE

A threat modelling framework identifying security risks: Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, and Elevation of Privilege.

Example: Asking "Could someone spoof a teacher's login?" while reviewing a design.

String

A data type for a sequence of characters, such as text.

Example: name = "Priya"

Structure Chart

A hierarchical tool showing how a system is divided into modules, functions within those modules, and their relationships. Used extensively in the Design phase.

Example: A "Process Results" module split into "Read Marks", "Calculate Average" and "Print Report".

Structured Data

NESA

Data with a high degree of organisation, such that it can easily be analysed and processed using algorithms. The organisation of the data takes on a form that captures the properties and behaviours of the source the data represents.

Example: A table of students with columns for ID, name and year, where every row has the same fields, so a program can sort and filter it.

Structured Query Language (SQL)

NESA

Specialist programming language used to manage data and access data in relational database management systems.

Example: SELECT name FROM Students WHERE year = 12; lists the names of the Year 12 students.

Stub

A placeholder subroutine that stands in for code not yet written, so the rest of the program can be tested.

Example: def calculate_tax(pay): return 0 while the real tax rules are still being written.

Subclass

A class that inherits the attributes and methods of another class and may add or override them; also called a child class.

Example: Book is a subclass of LibraryItem.

Subprogram

A named, reusable block of code (a function, procedure or subroutine) that performs one task.

Example: calculate_gst(price)

Superclass

A class whose attributes and methods are inherited by another class; also called a parent or base class.

Example: LibraryItem is the superclass of Book and DVD.

Supervised Learning

A machine learning model trained on a labelled dataset where both inputs and correct outputs are provided, enabling the model to learn the mapping between them.

Example: Training on house photos labelled with their sale prices.

See also: Unsupervised Learning, Machine Learning

Support and Confidence

Measures used in data mining: support is the share of all records containing both items, and confidence is the share of records with the first item that also contain the second.

Example: Three of five baskets have both games (support 0.6) and three of the four Reef Runner baskets do (confidence 0.75).

Symmetric Encryption

A fast encryption method (like AES-256) where the same key is used for both encryption and decryption. Fast but requires secure key distribution.

Example: Encrypting a zip file with AES and sharing the same password with a friend.

See also: Asymmetric Encryption

Syntax Error

A violation of a programming language's grammar rules that prevents the code from running. Usually flagged by the IDE during compilation.

Example: Forgetting the colon in if x > 5.

See also: Logic Error, Runtime Error

System Boundary

The line that separates what a system will do and contain from the external people and systems it interacts with.

Example: Loans and overdue lists are inside the boundary; email reminders are outside.

Systems Thinking

NESA

An understanding of how related objects or components interact to influence how systems function. Students are provided with opportunities to recognise the connectedness of, and interactions between phenomena, people, places and events in local and wider contexts and consider the impact of their decisions. Understanding the complexity of systems and the interdependence of components is important for scientific research and for the creation of solutions to technical, economic and social issues.

Example: Seeing that adding a self-serve kiosk to the canteen affects queue length, staffing and food waste, not only the ordering step.

T

TCP Three-Way Handshake

The SYN, SYN-ACK, ACK exchange that opens a reliable TCP connection before any data is sent.

Example: A browser sends SYN to a web server, receives SYN-ACK and replies ACK before the TLS handshake begins.

TCP/IP

The core internet protocols: IP addresses and routes packets; TCP makes sure they all arrive, in order and without errors.

Example: Loading a web page relies on TCP/IP to deliver every packet of the page.

Technical Debt

The future cost of rework caused by choosing a quick fix now instead of a better solution.

Example: Hard-coding prices to meet a deadline, then having to change them in 20 places.

Tell, Don't Ask

A design guideline that an object should be told to do something through a method rather than having its data read and the decision made by the caller.

Example: Call member.borrow(item) instead of checking len(member.loans) and appending to it.

Template Engine

A tool that combines an HTML template with data to produce a web page.

Example: Jinja2 filling {{ student.name }} in a Flask page.

Test Case

A single test: the input or action, the expected result, and the actual result.

Example: Input 101 → expected "Invalid mark" → actual "Invalid mark" ✔

Test Data

Inputs chosen to check a program works, including normal, boundary and faulty or abnormal values.

Example: Marks of 50, 0, 100, −1 and "abc".

Test Set

Data held back entirely until final evaluation to provide an unbiased estimate of real-world model performance. Should never be used during development or hyperparameter tuning.

Example: Keeping 20% of photos aside to measure the finished model's accuracy.

See also: Training Set, Validation Set

Threat Modelling

Systematically identifying what could go wrong with a system's security, how likely it is, and how to prevent it, usually during design.

Example: Using STRIDE on a data flow diagram to list threats to each process.

Time to Live (TTL)

The number of seconds a DNS answer may be cached before it must be looked up again.

Example: An A record with a TTL of 3600 is reused for an hour without asking the authoritative server.

TLS (Transport Layer Security)

A modern cryptographic protocol that provides secure, encrypted communication over a network. The successor to SSL, used by HTTPS to secure web traffic.

Example: The encryption behind the padlock in a browser address bar.

See also: HTTPS, Symmetric Encryption

Top-Down Design

Designing a system by starting with the whole problem and breaking it into smaller and smaller parts.

Example: "Run canteen app" → "take orders", "take payments", "print dockets".

Trace Table

A table that records the value of each variable, and each decision, after every step as an algorithm is worked through by hand.

Example: A trace table for a loop has a column for i and a column for total, with a new row for each pass.

Training Set

The portion of a dataset (typically 70–80%) used by an algorithm to learn patterns and adjust weights. The model sees these examples repeatedly during training.

See also: Validation Set, Test Set

Tree

A hierarchical data structure of nodes, where each node has one parent (except the root) and may have children.

Example: A computer's folder structure.

Two's Complement

The standard method for representing negative integers in binary by inverting the bits of the positive equivalent and adding one. Enables efficient arithmetic on signed numbers.

Example: −5 in 8 bits: 00000101 → invert to 11111010 → add 1 → 11111011.

See also: Integer

U

UART (Universal Asynchronous Receiver-Transmitter)

A two-wire serial protocol (TX and RX) that requires no clock signal, used for serial communication between microcontrollers and computers.

Example: An Arduino sending sensor readings to a laptop over USB serial.

See also: I2C, SPI

UML (Unified Modeling Language)

A standardised visual language for specifying, visualising, constructing, and documenting software systems. HSC-relevant diagrams include Class, Use Case, Sequence, and Activity Diagrams.

Example: A class diagram and a use case diagram for a library system.

See also: Class Diagram, Use Case Diagram

Unauthorised Access

Viewing, changing or using a system or data without permission.

Example: A former employee still logging in to the payroll system after leaving.

Underfitting

A model error where the algorithm is too simple to learn the underlying patterns in training data, resulting in poor performance on both training and test sets.

Example: Fitting a straight line to data that clearly curves.

See also: Overfitting

Unicode

The character standard covering the writing systems of the world, usually stored as UTF-8.

Example: Storing "Nguyễn" and "日本" correctly in a database.

Unit Testing

The practice of testing individual units (functions, methods, classes) in isolation to verify correct behaviour. Foundation of automated test suites and CI/CD.

Example: assert add(2, 3) == 5

See also: CI/CD, UAT

Unit, Subsystem and System Testing

Testing at three levels: single units such as functions, groups of units working together, and the whole system.

Example: Test add_to_cart(), then the checkout subsystem, then a full order from login to receipt.

Unsupervised Learning

A machine learning model that analyses unlabelled data to find hidden patterns or groupings autonomously, without being told what the correct output should be.

Example: Grouping shoppers into clusters by buying habits, with no labels given.

See also: Supervised Learning, Machine Learning

Usability

How easily users can learn and use software to reach their goals.

Example: Testing whether new students can find their timetable within 30 seconds.

User Acceptance Testing (UAT)

The final testing phase where actual users test the software in real-world scenarios to ensure it meets requirements and is ready for production deployment.

Example: The canteen manager tries the finished ordering app before it goes live.

Use Case Diagram

A UML diagram representing interactions between users (actors) and the system to achieve specific goals (use cases). Helps define system scope and requirements.

Example: A "Student" actor linked to "Borrow Book" and "Return Book".

See also: UML, Functional Requirements

User Experience (UX)

NESA

The usability, ease of use, and enjoyment provided in the interaction between the customer and the product.

Example: Cutting checkout from five steps to two after user testing.

User Interface (UI)

NESA

The means by which users interact with computer hardware or software. In software, this usually comprises fields for text and number entry, mouse pointers, buttons and other graphical elements. In hardware, switches, dials and light-emitting diodes (LEDs) provide information about the interactions between a user and a machine.

Example: Buttons, forms and menus in an app.

User Stories

Requirement statements written from an end-user's perspective in the format: "As a [role], I want [feature] so that [benefit]." Core to Agile development.

Example: "As a student, I want to see my timetable so that I know where to go."

See also: Acceptance Criteria, Agile

V

Validation Set

Data used during development to tune hyperparameters and compare different model configurations. Separate from training data but evaluated during development, unlike the test set.

Example: Comparing models with 3, 5 and 7 layers on held-out data before the final test.

See also: Training Set, Test Set

Variable

A named location in memory used to store data that can change during program execution. Variables have names, types, and scope.

Example: score = 0

See also: Array, Data Dictionary

Velocity

The number of story points a team completes in one sprint, averaged over past sprints to forecast the remaining work.

Example: An average of 7 points a sprint with 5 points left forecasts one more sprint.

Version Control (Git)

A system that tracks every change to code, allowing developers to revert to previous states, create branches, and collaborate safely. Git is the industry standard.

Example: git commit -m "Add login page" saves a snapshot you can return to.

See also: Code Review

Viewport

The visible area of a web page in the browser window.

Example: <meta name="viewport" content="width=device-width">

Virtual Personal Assistant

Software that uses speech recognition and ML to understand requests and carry out tasks.

Example: Asking Siri to set a timer.

Voltage Divider

Two resistors in series that share a supply voltage, so the voltage at their joint depends on their resistances.

Example: An LDR and a 10 kΩ resistor form a voltage divider whose midpoint voltage is read by an ADC.

Volume Testing

Testing with a large amount of data or many users to check speed and stability.

Example: Feeding a program 100 000 orders to see whether it slows or fails.

Vulnerability

A weakness in software, hardware or processes that an attacker could use to cause harm.

Example: A login form that does not limit the number of password attempts.

Vulnerability Assessment

A systematic review that finds, ranks and reports security weaknesses in a system.

Example: A scanner reports an outdated library with a known exploit and rates it high risk.

W

Watch

A debugger feature that shows the value of a chosen variable or expression as the program runs.

Example: Watching len(queue) to see when the queue empties.

Watchdog Timer

A hardware timer that restarts the controller if the program does not reset it regularly, which shows the program has stopped responding.

Example: A drone's controller restarts if its main loop freezes.

Waterfall

A linear, sequential development approach where each phase (requirements, design, implementation, testing) must be completed before the next begins. Best suited for large projects with fixed, well-understood requirements.

Example: Finishing and signing off the full design before any code is written.

See also: Agile, SDLC

Web Accessibility (WCAG)

International guidelines developed by the W3C to make web content usable for people with various disabilities. Covers visual, hearing, motor, and cognitive disabilities.

Example: Adding alt text so a screen reader can describe an image.

Web Browser

The client application that requests web pages, then renders HTML and CSS and runs JavaScript.

Example: Chrome, Firefox and Safari.

Web Server

Software (and the computer running it) that receives HTTP requests and sends back web pages, files or data.

Example: Nginx serving a Flask app.

Weighted Decision Matrix

A table that scores options against criteria and multiplies each score by the criterion's weight to compare the totals.

Example: A school scores three CMS types against five criteria and finds the headless CMS has the highest weighted total.

Wireframe

A low-fidelity layout sketch of a single screen showing the placement of UI elements (buttons, text fields, navigation). Created early in Design phase before detailed visual design.

Example: A grey-box sketch showing where the logo, menu and search bar go.

See also: Prototype, Storyboard

White-Box Testing

NESA

A testing technique used to examine the internal workings of an application including the design, code and inner workings of software. This technique gives the ability to verify the flow of inputs and outputs through the application.

Example: Writing tests that make every IF statement take both its true and false paths.

See also: Black-Box Testing, SAST

WAGILE

A hybrid of Waterfall and Agile where high-level phases are planned in advance, but internal development is iterative. Pragmatic approach balancing both methodologies.

Example: A fixed-date project with a planned design phase, then Agile sprints for development.

See also: Agile, Waterfall

World Wide Web Consortium (W3C)

NESA

The World Wide Web Consortium is the international standards organisation for the world wide web. All of the standards used for web development are defined by this organisation.

Example: WCAG accessibility guidelines are published by the W3C's Web Accessibility Initiative.

WSGI

The Python standard that lets a web server such as Gunicorn pass requests to a web application such as a Flask app.

Example: Nginx passes a request to Gunicorn, which calls the Flask app through WSGI.

XSS (Cross-Site Scripting)

A vulnerability where an attacker injects malicious client-side scripts into web pages viewed by other users. Caused by improper input validation and output encoding.

Example: A comment containing <script> that runs in every reader's browser.

See also: CSRF, SQL Injection

Zero-Day Vulnerability

A security flaw that attackers know about before the developer has released a fix.

Example: An exploit for a browser bug used in attacks the same day it is discovered.
