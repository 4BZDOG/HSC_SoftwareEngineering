## Quick Assessment Checklist

Before your HSC exam, ensure you can explain:

### Secure Software Architecture
- [ ] CIA triad and the three additional concepts (Authentication, Authorisation, Accountability)
- [ ] All 8 SDLC phases and security gates in each
- [ ] Three privacy by design pillars
- [ ] Five code management testing strategies
- [ ] Real-world vulnerabilities: XSS, CSRF, SQL injection, race conditions
- [ ] Social, ethical, legal impacts on employment and data security

### Software Engineering Project
- [ ] Viability and feasibility analysis
- [ ] Direct, phased, parallel, pilot implementation methods
- [ ] Waterfall, Agile, WAgile development approaches
- [ ] Project management tools and communication
- [ ] QA methods and testing strategies
- [ ] Version control and documentation importance

### Software Automation
- [ ] Three automation mechanisms: DevOps, RPA, BPA
- [ ] Four ML training models
- [ ] Three algorithms: Linear regression, logistic regression, KNN
- [ ] Supervised vs unsupervised learning
- [ ] Societal impacts: employment shifts, accessibility, wealth distribution
- [ ] Bias sources and mitigation strategies

### Programming for the Web
- [ ] HTTP vs HTTPS security differences
- [ ] TLS handshake and encryption
- [ ] Session management and authentication flows
- [ ] Database security: parameterised queries, preventing injection
- [ ] CMS structure and advantages
- [ ] PWA capabilities and offline support
- [ ] Open-source licence implications

## Syllabus Outcome Definitions

### SE-12-01
Students develop and evaluate software solutions that meet specified requirements using structured development methodologies.

### SE-12-02
Students design, develop and evaluate strategies for managing the software development process and team collaboration.

### SE-12-03
Students apply secure software design principles and practices to mitigate vulnerabilities and risks.

### SE-12-04
Students explain the role of fundamental security concepts and privacy principles in software development.

### SE-12-05
Students evaluate the impact and implications of software and security decisions on society, ethics, and business.

### SE-12-06
Students apply and evaluate security testing and hardening methodologies throughout the development lifecycle.

### SE-12-07
Students design and develop secure code using defensive programming practices.

### SE-12-08
Students evaluate and apply testing methodologies to verify software security and performance.

### SE-12-09
Students synthesise findings and develop recommendations for secure software solutions.
