# 📋 SOFTWARE AUTOMATION

### Year 12 Focus: Software Automation (Outcomes SE-12-01 to SE-12-09)

---

## **PART 1: ALGORITHMS IN MACHINE LEARNING**

### 1. How ML Supports Automation

**Outcomes:** SE-12-01, SE-12-03, SE-12-09

Machine learning supports automation through three key mechanisms:

- **DevOps:** Software development practices that unify development and operations teams to deliver software continuously and reliably
- **Robotic Process Automation (RPA):** Software bots that automate repetitive, rule-based digital tasks
- **Business Process Automation (BPA):** Technology used to automate entire end-to-end business workflows

### 2. Distinguishing AI from Machine Learning

**Outcomes:** SE-12-03

- **Artificial Intelligence (AI):** The broad concept of machines performing tasks requiring human-like intelligence (includes rules-based systems, expert systems, and learning systems)
- **Machine Learning (ML):** A specific subset of AI where systems learn from data, identify patterns, and improve without being explicitly programmed for each scenario

### 3. Models of Training Machine Learning

**Outcomes:** SE-12-03

ML systems can be trained through four primary models:

- **Supervised Learning:** Training on labelled data where both inputs and correct outputs are provided
- **Unsupervised Learning:** Finding patterns in unlabelled data without predetermined answers
- **Semi-Supervised Learning:** Combining small amounts of labelled data with large pools of unlabelled data
- **Reinforcement Learning:** Learning through trial and error via rewards and penalties from interaction with an environment

### 4. Common Applications of ML Algorithms

**Outcomes:** SE-12-03, SE-12-05

- **Data Analysis and Forecasting:** Using regression algorithms to predict future outcomes from historical patterns
- **Virtual Personal Assistants:** Speech recognition, natural language processing, and text-to-speech systems
- **Image Recognition:** Identifying objects, faces, and patterns in visual data using deep learning

### 5. Design Models: Decision Trees and Neural Networks

**Outcomes:** SE-12-03, SE-12-08

- **Decision Trees:** Tree-structured models representing sequences of binary decisions, highly interpretable but prone to overfitting
- **Neural Networks:** Layered structures inspired by biological brains, capable of learning complex non-linear relationships

### 6. Types of Algorithms Associated with ML

**Outcomes:** SE-12-02, SE-12-03

The syllabus specifies these key algorithms:

- **Linear Regression:** Predicting continuous values by fitting a straight line through data (y = mx + c)
- **Logistic Regression:** Predicting binary classification outcomes using a sigmoid probability function
- **K-Nearest Neighbour (KNN):** Classifying data points based on the majority class of their K nearest neighbours in the training set

## **PART 2: PROGRAMMING FOR AUTOMATION**

### 7. ML Regression Models Using OOP

**Outcomes:** SE-12-02, SE-12-08

Design, develop, and apply regression models using Object-Oriented Programming:

- **Linear Regression:** OOP implementations create model objects with fit() and predict() methods
- **Polynomial Regression:** Extending linear regression to model non-linear (curved) relationships
- **Logistic Regression:** Binary classification using sigmoid activation, returning probability outputs

### 8. Neural Network Models Using OOP

**Outcomes:** SE-12-02, SE-12-08

Apply neural network models using OOP paradigms:

- Instantiate neural network objects with specified architecture (layers, neurons, activation functions)
- Train models using backpropagation to adjust weights and minimize prediction error
- Make predictions on new data using the learned weights

## **PART 3: SIGNIFICANCE AND IMPACT OF ML AND AI**

### 9. Impact of Automation on Individuals, Society, and Environment

**Outcomes:** SE-12-05

- **Worker Safety:** Automation in dangerous environments (mining, power lines, hazardous materials) reduces human injury and fatalities
- **Accessibility for People with Disability:** AI enables computer vision aids, speech interfaces, and autonomous vehicles for greater independence
- **Employment and Skills:** Automation displaces routine jobs while creating demand for skills in data science, ML operations, and AI ethics
- **Production Efficiency and Environment:** ML optimises supply chains and energy systems, though training models requires significant computational resources
- **Economy and Wealth Distribution:** Automation increases productivity but raises concerns about wealth concentration without appropriate policy interventions

### 10. Human Behaviour Patterns Influencing ML and AI

**Outcomes:** SE-12-04, SE-12-05

- **Psychological Responses:** Users must understand when interacting with AI; transparent communication builds trust and ensures appropriate human oversight
- **Acute Stress Response:** Critical environments require interface designs that prioritize essential information and minimize cognitive load
- **Cultural Protocols:** Global AI systems must respect diverse communication norms and comply with local privacy laws
- **Belief Systems:** AI systems must be explainable to allow individuals to challenge decisions that conflict with their values

### 11. Human and Dataset Source Bias in ML and AI

**Outcomes:** SE-12-04, SE-12-05

Bias can arise from multiple sources:

- **Data Reflecting Historical Prejudices:** Training on biased historical data perpetuates discriminatory patterns
- **Unrepresentative Datasets:** Models trained on non-diverse data produce systematically unfair outcomes for underrepresented populations
- **Developer Unconscious Bias:** Engineers may unconsciously select or weight data confirming their pre-existing assumptions
- **Self-Reinforcing Feedback Loops:** Biased model outputs can influence data collection, creating cycles that entrench bias

**Mitigation Practices:**
- Ensure training datasets are representative and diverse
- Conduct fairness audits across demographic subgroups
- Build diverse development teams to identify potential biases
- Design explainable systems for consequential decisions

## 📖 Why Software Automation Matters

The Software Automation focus area enables students to:
- Extend knowledge of programming and its diverse real-world applications
- Design and implement code using OOP principles and design thinking
- Understand fundamental machine learning concepts and neural networks
- Critically evaluate the societal, ethical, and environmental impacts of automation technology
- Develop practical experience with ML model design and deployment

This content prepares students for careers in emerging technologies and enables informed citizenship regarding AI's impact on society.
