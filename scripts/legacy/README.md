# Legacy one-off scripts

These scripts made one-time edits to the pages (adding emoji, fixing diagram markup,
adding the Glossary link to the nav, restyling outcome lines). Their changes are already
in the pages, and the markup has moved on since, so **do not re-run them**: some would
now duplicate or undo later work.

Current maintenance scripts live in `scripts/`. Navigation, footer and topic icons are
applied by `scripts/site-chrome.py`.
